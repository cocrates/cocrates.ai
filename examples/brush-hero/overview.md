# 이빨나라의 작은 영웅

## 기본 정보
- 제목: 이빨나라의 작은 영웅
- 타겟 연령: 5세
- 쪽 수: 11쪽
- 테마/장르: 위생/건강 — 모험 동화
- 톤/분위기: 밝고 유쾌하며, 약간의 긴장감 속에 empowerment(할 수 있다는 용기) 있는 분위기

## 스토리 요약
5살 소년 훈은 이빨 닦기를 싫어한다. 어느 날 밤, 꿈속에서自己的 입 안의世界 — 「이빨나라」로 순간이동한다. 하얀 성(치아)들이 모여 사는 아름다운 나라지만, 설탕 괴물들(충치 벌레)이 침략해 곧 무너질 위기에 처해 있다. 훈은 이빨나라 시민들과 함께 「치카치카 방패」(칫솔)와 「거품 마법」(치약)으로 설탕 괴물들을 물리치고 이빨나라를 구한다. 다음 날 아침, 훈은 거울 앞에서 당당하게 이빨을 닦는다 — 영웅처럼.

## 캐릭터 개요
- 주인공: 훈 (5살 소년) — 이빨 닦기를 귀찮아하지만, 속은 착하고 용감한 아이
- 조연: 하얀이 (이빨나라 주민, 동글동글한 치아 캐릭터) — 훈에게 도움을 요청하는 친구
- 적: 설탕 괴물 (달콤하지만 위험한 충치 벌레 무리)

## 배경 개요
- 세계: 이빨나라 — 훈의 입안의 작은 세계. 하얀 치아 성들이 늘어서 있는 마을
- 주요 지역: 이빨 광장 (치아 성들이 모여 있는 곳)
- 주요 장소: 설탕 괴물 성 (어둡고 끈적한 곳 — 달콤한 성벽)

## 일러스트 스타일
- 미디아: 부드러운 디지털 페인팅 (소프트 브러시, 물감 번짐 느낌)
- 팔레트: 밝은 파스텔 톤 (하늘색, 연두색, 분홍색) + 설탕 괴물만 어두운 보라/갈색
- 라인: 둥글고 부드러운 윤곽선 (공격적이지 않음)
- 분위기: 모험감 + 귀여움 + 약간의 긴장감
- 참고작: 없음 (오리지널)

## 제약 조건
- 금기사항: 충치나 통증을 무섭거나 혐오스럽게 묘사하지 않음. 괴물도 너무 무섭지 않게 — 「장난꾸러기 악당」 톤
- 범위 밖: 실제 치과 기구나 의료 절차는 등장하지 않음 (치과 공포 유발 방지)

## Validation Criteria

| Criterion | How to verify |
|-----------|---------------|
| 5살 아이가 그림만 보고도 대략적인 흐름을 파악할 수 있다 | 각 페이지의 그림이 이야기 전달에 충분한가? |
| 읽어주기 20초 이내 | 각 페이지 렌더링 텍스트를 소리 내어 읽었을 때 20초 이내 |
| 페이지 넘김 훅이 마지막 페이지를 제외하고 존재한다 | 각 페이지 끝에 "다음에 뭐가 벌어질까?"하는 호기심이 있는가? |
| 마지막 페이지가 교훈적 설교가 아닌 장면으로 끝난다 | 마지막 페이지에 "그래서 매일 이빨 닦아야 해" 같은 직접적 교훈이 없는가? |
| 이닦기를 하고 싶게 만드는 empowerment 느낌이 있다 | 주인공이 이닦기로 승리하는 장면이 있는가? |
| 안전하고 나이에 맞는다 | 금기사항에 없는 내용만 있는가? |

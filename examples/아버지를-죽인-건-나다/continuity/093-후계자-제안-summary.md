# Episode 093: 후계자 제안 — Summary

## Scenes Covered
| Sc | Title | Key Events |
|---|---|---|
| 1 | 미끼의 조건 | 진우는 도현의 사흘 시한과 후계자 미끼의 위험을 계산하고, 제자의 표식 판독·혁의 퇴로·가환의 외부 신호 역할을 확정했다. |
| 2 | 이름으로 열린 길 | 침투조는 흑풍루 본거지 침투 회랑에서 대나무 표식과 검은 삼중선을 대조했다. 표식보다 진우의 봉인 반응이 문을 열었다. |
| 3 | 주인을 묻는 문 | 중앙 금고는 기록판의 ‘후계자’ 선언으로 열리지 않았고, 진우의 혈맥을 주인 확인 절차로 요구했다. 진우는 봉인 파열과 통증을 감수해 문을 열었다. |
| 4 | 진우의 이름이 적힌 패 | 금고에서 도현 치료에 필요한 원액과 어머니의 생존을 증명하는 호흡·혈맥 보존 기록을 확보했다. 별도 소유 확인 패의 주인란에는 ‘서진우’가 기록되어 있었다. |

## Key Events (Episode Level)
- 진우는 후계자라는 이름을 흑풍루 내부 금고 접근 미끼로 실행했다.
- 제자의 제한된 표식 지식으로 침투 회랑을 통과했으나, 실제 접근 권한은 진우의 봉인 반응과 연결되어 있었다.
- 금고는 후계자 선언이 아니라 혈맥 기반 주인 확인을 요구했고, 진우는 왼팔 봉인 파열과 통증을 감수했다.
- 금고 안에서 흑풍루주 원액을 확보했다.
- 봉인패의 호흡·혈맥 보존 기록이 어머니의 생존을 증명하는 물증임을 가환이 판독했다.
- 소유 확인 패에는 어머니가 아닌 진우의 이름이 기록되어, 후계자 등록·계약 구조의 새 의혹이 발생했다.

## New Unresolved Threads
- **TH-135 — 금고 소유자 등록:** 봉인패에 진우가 소유자로 기록된 이유·등록 시점·계약 구조는 미확정. Expected Window: 094–095.
- **TH-136 — 원액의 실제 치료 효력:** 원액은 확보했으나 도현에게 투여하지 않았고, 배합·부작용·사흘 시한과의 관계는 미확정. Expected Window: 094.
- **TH-137 — 금고 두 번째 잠금:** 원액·봉인패 확보 직후 금고 안쪽 잠금이 재작동했다. 봉인 방식과 탈출 경로는 미확정. Expected Window: 094.
- **TH-138 — 어머니 생존 봉인패의 위치 정보:** 패는 생존을 증명하지만 어머니의 현재 위치·상태·구출 경로는 알려 주지 않는다. Expected Window: 094–101.
- **TH-126 — 봉인 해제 후 남은 시간:** 혈맥 주인 확인으로 진우의 왼팔 봉인 파열과 통증이 재발했으나 남은 시간·후유 대가는 미확정. Expected Window: 094.
- **TH-127 — 이동하는 감옥의 행렬:** 생존 봉인패가 어머니의 현재 위치를 확정하지 않아 행렬의 최종 목적지는 여전히 미확정. Expected Window: 094.
- **TH-131 — 어머니 사망 주장:** 봉인패가 생존을 지지하지만 사자의 주장과 패의 작성 시점·현재 상태는 대조되지 않았다. Expected Window: 094–095.
- **TH-133 — 흑풍루주의 원액 침투:** 원액을 확보했으나 본거지 탈출과 도현 투여가 남았다. Expected Window: 094.
- **TH-134 — 스승의 거부 명령:** 후계자 교육 명령의 핵심 목적은 확인했으나 등록 원문·스승의 거부 대가는 미확정. Expected Window: 094–095.

## Resolved Threads
- **TH-133의 원액 위치:** 흑풍루 본거지 중앙 금고에 원액이 보관되어 있음은 확인하고 병을 확보했다. 치료 효력은 TH-136으로 분리한다.
- **TH-131의 생존 단서:** 어머니의 생존을 증명하는 봉인 기록은 확보했으나 현재 위치·상태 확정은 TH-138로 남긴다.

## Narrative Hooks for Next Episode
금고 안쪽 잠금이 재작동하는 가운데, 진우는 원액과 어머니의 생존 봉인패를 품고 탈출해야 한다. 봉인패의 주인은 어머니가 아니라 진우 자신으로 기록되어 있어, 다음 회차는 금고 봉인과 진우의 등록 경위를 압박한다.

# Episode 014: 열흘 앞선 칼 — Summary

## Scenes Covered
| Sc | Title | Key Events |
|---|---|---|
| 1 | 잠기기 전의 무기고 | 진우와 백무진이 열흘 앞선 쿠데타 명령에 따라 외당 무기고 입구를 선점했다. 진우는 인장을 바로 쓰지 않고 자물쇠의 선행 흔적과 출입 장부의 빈 용무 칸을 확인한 뒤 후계자 도착을 먼저 기록했다. |
| 2 | 끊긴 첫 운송 | 진우가 무기 상자 수량보다 출입 장부의 빈 칸과 운송표 인수 시각을 대조했다. 첫 자금 운송에 연결된 상자를 공개 봉인하고 운송을 취소했으며, 무진은 동료의 이름을 넘기지 않는 조건으로 출입선을 봉쇄했다. |
| 3 | 운송표의 이름 | 운송표에서 남궁가와 남궁혁의 이름을 확인했지만 위조·동맹 여부는 판단하지 않았다. 남궁혁이 무기고 입구에 직접 도착해 진우에게 결투를 청했고, 진우는 결투 승낙과 동맹 결론을 보류했다. |

## Key Events (Episode Level)
- 진우는 열흘 앞선 쿠데타의 실행 거점인 외당 무기고를 후계자 인장과 공개 기록으로 선점했다.
- 자물쇠의 선행 흔적과 장부의 빈 용무 칸을 통해 누군가 이미 무기고를 쿠데타 명령에 맞춰 움직였음을 확인했다.
- 운송표와 빈 장부 칸의 시각을 대조해 첫 자금 운송을 취소하고, 무기고 통제권을 실제 조치로 전환했다.
- 무진은 외당 제자의 이름을 공개하지 않는 대신 첫 출입선을 잠그는 조건으로 협력했다.
- 남궁혁의 이름이 적힌 운송표가 드러났고, 남궁혁은 직접 찾아와 운송표 해명보다 결투를 먼저 청했다.

# Episode 094: 주인으로 등록된 아이 — Summary

## Scenes Covered
| Sc | Title | Key Events |
|---|---|---|
| 1 | 선택된 아이의 기록 | 진우는 소유자 패의 인계 기록과 도현의 반출 확인 봉랍을 대조해, 자신이 흑풍루의 선택된 아이였고 도현이 자신을 빼돌렸을 가능성을 확인했다. |
| 2 | 원액을 드는 손 | 진우는 자신의 피로 원액 보관함을 열고 원액을 확보했다. 생존 봉인패와 소유 확인 패를 함께 보존한 순간 금고 봉인선이 퍼졌다. |
| 3 | 닫힌 수로 | 침투조는 서쪽 탈출 수로로 이동했으나 주인 확인 뒤 외부 탈출 권한이 사라졌다. 진우는 도현을 살리기 위해 원액을 버리지 않았고 수로가 완전히 닫혔다. |
| 4 | 문밖에 선 사람 | 금고문 앞에서 흑풍루주의 혈인 반응과 도착 신호가 나타났다. 문밖의 존재가 진우의 이름을 불렀고, 진우는 대답하지 않은 채 원액을 지켰다. |

## Key Events (Episode Level)
- 진우는 자신이 흑풍루 혈맥 의식의 선택된 아이였음을 인계 기록에서 확인했다.
- 도현의 북문서가 반출 확인 봉랍 흔적이 선택된 아이를 흑풍루 밖으로 빼돌린 물증으로 남아 있었다.
- 진우는 원액을 피로 개방해 확보했고, 원액은 아직 도현에게 투여하지 않았다.
- 소유자 확인을 완료한 대가로 금고의 외부 탈출 권한과 서쪽 수로가 봉인되었다.
- 흑풍루주의 혈인 반응과 목소리가 금고 밖에 도착했으며, 직접 대면은 다음 회차로 넘어간다.

## New Unresolved Threads
- **TH-139 — 흑풍루주의 금고 앞 대면:** 문밖 존재가 진우의 이름을 불렀고 혈인 반응이 일치했다. 얼굴·정체·첫 요구는 미확정. Expected Window: 095.
- **TH-140 — 도현의 빼돌림 대가:** 반출 봉랍은 물증이 되었으나 도현이 누구와 어떤 대가를 치렀는지는 미확정. Expected Window: 095–096.
- **TH-136 — 원액의 실제 치료 효력:** 원액을 확보했으나 투여하지 않았다. 배합·부작용·도현 치료 결과는 미확정. Expected Window: 095.
- **TH-137 — 금고 두 번째 잠금:** 금고 전체와 서쪽 수로가 봉인되었고 탈출 구조는 미확정. Expected Window: 095.
- **TH-135 — 금고 소유자 등록:** 진우가 선택된 아이로 등록된 시점과 등록 주체는 미확정. Expected Window: 095–096.
- **TH-138 — 어머니 생존 봉인패의 위치 정보:** 생존은 증명되었으나 현재 위치·상태·구출 경로는 미확정. Expected Window: 095–101.
- **TH-126 — 봉인 해제 후 남은 시간:** 금고 개방과 원액 회수 중 왼팔 봉인 반응이 재발했으나 남은 시간·후유 대가는 미확정. Expected Window: 095.

## Resolved Threads
- **TH-135의 선택된 아이 여부:** 진우가 흑풍루 혈맥 의식의 선택된 아이였다는 사실은 인계 기록으로 확인했다. 등록 시점·주체는 새 미해결로 남긴다.
- **TH-137의 탈출로 폐쇄:** 소유자 확인 뒤 서쪽 수로와 금고 외부 권한이 닫혔음은 확인했다. 탈출 방법은 TH-137 후속 문제로 유지한다.

## Narrative Hooks for Next Episode
금고문 밖에서 흑풍루주의 혈인 반응과 목소리가 진우를 호출한다. 진우는 원액과 생존 봉인패를 품은 채 대답하지 않았고, 흑풍루주가 금고를 연 대가를 직접 말할 순간을 앞둔다.

# Staging: 039-내부자-거래

## Situation
Episode 039에서 Episode 038 직후, 북문서가 본가 지하 보관실의 검증 기록을 빼내려는 내부자와 진우 일행이 맞서는 거래 상황.

## Location
- `locations/북문서가-본가.md + 지하 보관실`
- `locations/북문서가-본가.md + 지하 통로 입구`
- `locations/북문서가-본가.md + 가주전-회랑 접속부`

## Cast and states
| Character | State | Initial position / movement |
|---|---|---|
| 서진우 | base | 지하 보관실 벽면 선반 앞 → 지하 통로 입구 계단 위 → 회랑 접속부 중앙 |
| 남궁혁 | base | 보관실 출입문 옆 → 계단 아래쪽 → 진우의 오른쪽 뒤 |
| 봉인된 또 다른 아이 | 탈출-상태 | 보관실 안쪽 벽면 → 진우 뒤쪽 → 회랑의 기둥 옆 |
| 흑풍루 내부자 | base | 지하 통로 반대편 어둠 → 계단 아래 → 회랑 맞은편 문턱 |

## Situation props
- 장부 사본, 검은 삼중선이 찍힌 납작한 인계패, 아이의 보호용 붕대, 거래 조건 쪽지, 빈 약 그릇.

## Ambient / blocking locks
- 낮은 천장과 벽면 선반이 시야를 끊어, 내부자는 처음에 검은 소매와 손만 보인다.
- 인계패는 내부자가 손에 쥐고 있다가 거래의 대가로 진우에게 던진다.
- 아이는 내부자에게 가까이 가지 않으며, 진우와 혁 사이의 보호선 안에 머문다.
- 거래가 깨질 때 내부자는 아이를 공격하지 않고 회랑 쪽으로 물러나 다음 회합 장소가 적힌 쪽지만 남긴다.

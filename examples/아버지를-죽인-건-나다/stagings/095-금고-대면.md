# Staging: 095 금고 대면

## Situation
Episode 095의 봉인된 흑풍루 본거지 금고에서 진우 일행이 흑풍루주와 첫 대면하고, 원액을 지킨 채 의식장 옆 탈출 수로로 이동하는 상황.

- `locations/흑풍루-본거지.md` + `금고`
- `locations/흑풍루-본거지.md` + `의식장`
- `locations/흑풍루-본거지.md` + `탈출 수로`

## Fixed cast and states
| Character | State | Position / facing |
|---|---|---|
| 서진우 | `봉인-해제` | 원액 병과 생존 봉인패를 몸 안쪽에 보관하고 금고문·흑풍루주를 정면으로 상대 |
| 남궁혁 | `전장-복장` | 진우의 왼쪽 후방, 백색 장검으로 일행의 이동로와 흑풍루주의 손을 감시 |
| 가환 | `base` | 기록함·봉인패 가까이, 문서와 혈인 반응을 판독 |
| 진우의 스승의 제자 | `침투-준비` | 오른쪽 후방과 출구 사이, 대나무 표식 없이 잠금과 탈출 방향을 확인 |
| 흑풍루주 | `base` | 금고문을 통과한 뒤 진우와 일정 거리를 두고 서며, 붉은 혈인 반지를 노출 |

## Situation props and ambient
- 원액 병, 어머니 생존 봉인패, 진우 소유 확인 패, 도현의 반출 봉랍 기록, 검은 혈인 반지, 의식용 지팡이, 깨진 금고 잠금선.
- 붉은 등불, 약품·쇠 냄새, 멎었다 이어지는 수로 물소리, 금고문을 타고 번지는 낮은 혈인 공명.
- Scene 1–2는 금고문 안팎의 대면과 기록 대조에 고정한다. Scene 3에서 일행은 의식장 가장자리로 밀려나고, Scene 4에서 잠시 열린 탈출 수로로 이동한다.

# 050-살아-있는-배신자-추적

## Situation
Episode 050에서 진우와 혁이 흑풍루 감시자의 재·기름등 흔적을 따라가 다시 접촉하고, 봉인된 서찰을 지닌 채 감시자의 제한된 증언을 끌어내는 상황.

## Cast & States
| Character | State | Placement |
|---|---|---|
| 서진우 | base | 기록대와 납골 회랑 사이, 서찰을 몸에 보관 |
| 남궁혁 | base | 동쪽 입구와 감시자의 퇴로 사이 |
| 흑풍루 감시자 | base | 서쪽 납골 회랑에서 재 흔적을 지우며 이동 |

## Blocking & Props
- 진우는 봉인된 서찰을 열지 않은 채 오른손 안쪽에 보관하고, 왼손으로 재 흔적과 기름등 자국을 대조한다.
- 혁은 입구를 확보하며 감시자가 빠져나갈 수 있는 두 방향을 번갈아 막는다.
- 감시자는 빈 기름등과 재 주머니를 지니고, 문서 대신 진우의 서찰을 확인하려 한다.
- 진우는 서찰을 공개적으로 꺼내지 않고 봉랍의 세 줄만 보여 주어 감시자의 반응을 읽는다.

## Ambient / Span
꺼진 촛불, 남은 재, 식지 않은 밀랍 냄새, 납골 회랑의 긴 울림. 세 인물의 base 상태와 서찰 봉인은 장면 전체에서 유지된다.

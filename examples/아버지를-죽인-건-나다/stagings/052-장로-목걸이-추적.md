# 052-장로-목걸이-추적

## Situation
Episode 052에서 진우와 혁이 감시자의 두 번째 조건 증언을 북문서가 장로 대표에게 대조하고, 흑풍루 지하 금고의 원문에 접근할 열쇠를 추적하는 상황.

## Cast & States
| Character | State | Placement |
|---|---|---|
| 서진우 | base | 장로 대표를 정면으로 압박하는 중앙 위치, 봉인 서찰과 표식 조각 보관 |
| 남궁혁 | base | 출입과 증인선을 확보하는 오른쪽 회랑 |
| 장로 대표 | base | 장로회당 표결단 뒤, 목걸이형 금고리를 손으로 만지는 위치 |

## Blocking & Props
- 진우는 봉인 서찰을 열지 않은 채 표식 조각과 약재 분류표를 문서함 위에 둔다.
- 혁은 장로회당의 동쪽 출입과 회랑을 확인하며 증거의 이동을 막는다.
- 장로 대표는 흑단 지팡이와 장로회 인장을 사용하고, 오른쪽 귓불의 금고리와 목걸이형 금고리를 반복해서 만진다.
- 공개 증언이 끝나면 진우와 혁은 금고리의 형태를 확인하지만 즉시 빼앗지 않고 금고 접근 경로를 확보한다.

## Ambient / Span
북문서가 본가의 가문 등불, 먹물 냄새, 장로회당의 낮은 목소리, 문서함과 표결단. 세 인물의 base 상태와 봉인 서찰은 상황 전체에서 유지된다.

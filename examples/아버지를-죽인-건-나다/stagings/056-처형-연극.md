# Staging: 056 — 처형 연극

## Situation
Episode 056의 공개 처형 연극. Scene 2의 집행대 위 칼끝과 Scene 3의 석단 아래 상태 확인이 같은 새벽의 연속 상황이다.

## Location
- `locations/북문서가-본가.md` — `중정 공개 처형대` / `중정 공개 처형대 아래`

## Cast & States
| Character | State | Fixed position / movement |
|---|---|---|
| 서진우 | base | 처형대 남쪽에서 도현의 왼쪽 뒤를 향해 선다. 붉은 실 장검을 들고, Scene 3에서 석단 아래로 내려간다. |
| 서도현 | 처형대-복장 | 처형대 중앙의 죄수 고정쇠에 묶인다. Scene 2에서 몸으로 칼을 밀고, Scene 3에서 석단 아래로 쓰러진다. |
| 남궁혁 | base | 처형대 동쪽 회랑 입구와 증인선 사이를 지키며 기록과 퇴로를 통제한다. |
| 흑풍루의 사자 | base | 처형대 북쪽 회랑 쪽에서 칼과 도현의 상태를 확인한다. Scene 3에서 확인이 불완전한 채 물러난다. |

## Situation Props
- 처형 집행 기록과 분리된 처분 문서
- 봉인끈과 공개 기록판
- 붉은 실 장검
- 도현의 손목 봉인띠와 처형대 고정쇠
- 사자의 동전 모양 무명 금속패

## Sightline / Blocking Locks
- 사자는 회랑 쪽에서 처형대 위 칼과 쓰러진 도현의 상반신을 볼 수 있지만, 석단 아래의 상처와 검은 피는 직접 볼 수 없다.
- 혁은 동쪽 증인선을 닫아 사자가 처형대 남쪽으로 접근하지 못하게 한다.
- 진우는 칼을 비틀어 치명상을 피한 뒤 도현의 낙하를 석단 아래 그늘로 유도한다.
- Scene 3에서 진우만 석단 아래로 내려가 상처를 누르고, 혁은 위에서 증인선을 유지한다.

## Ambient / Continuity
- 새벽의 공개 집행. 본가 사람들의 웅성거림은 이름 없는 배경음으로만 처리하고, 의도된 발화는 네 명의 고정 cast 안에서만 발생한다.
- 도현의 내면 동기와 계약 전문은 이 staging에서 해설하지 않는다.

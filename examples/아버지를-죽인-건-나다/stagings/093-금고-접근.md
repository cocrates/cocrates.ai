# Staging: 093 금고 접근

## Situation
흑풍루 본거지 침투 회랑에서 중앙 금고까지, 후계자 인계 표식과 진우의 혈맥 반응으로 접근 권한을 확인하는 침투 상황.

## Locations
- `locations/흑풍루-본거지.md` + `침투 회랑`
- `locations/흑풍루-본거지.md` + `금고`

## Fixed cast and states
| Character | State | Position / facing |
|---|---|---|
| 서진우 | `봉인-해제` | 침투 회랑에서는 선두, 금고에서는 문 정면. 왼팔을 문에 댐 |
| 남궁혁 | `전장-복장` | 후방과 서쪽 수로를 번갈아 감시, 백색 장검을 뽑지 않은 상태 |
| 가환 | `base` | 진우 뒤쪽의 벽면, 지도 조각과 외부 신호를 확인 |
| 진우의 스승의 제자 | `침투-준비` | 진우의 왼편에서 대나무 표식·검은 삼중선 순서를 판독 |

## Situation props and ambient
- 대나무 표식, 검은 삼중선 인계 표식, 지도 조각, 붉은 실, 기록판, 검은 혈인문, 원액 병, 봉인패.
- 붉은 등불, 축축한 냉기, 약품·쇠 냄새, 낮은 물소리.
- Scene 2에서는 표식과 지도 조각이 이동하고, Scene 3에서는 기록판이 금고문 홈으로 이동하며, Scene 4에서는 원액 병과 봉인패가 진우에게 회수된다.
- 네 인물의 상대적 선두·후방·벽면 배치는 Scene 2–4에서 유지한다.

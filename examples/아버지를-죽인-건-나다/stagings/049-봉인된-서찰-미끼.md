# 049-봉인된-서찰-미끼

## Situation
Episode 049에서 진우와 혁이 흑풍루 납골당 봉인문 옆 석판 뒤의 서찰을 회수하고, 흑풍루 감시자를 서찰로 유인해 제한된 증언을 얻는 상황.

## Cast & States
| Character | State | Placement |
|---|---|---|
| 서진우 | base | 봉인문 옆 석판과 기록대 사이, 이후 중앙 기록대 앞 |
| 남궁혁 | base | 동쪽 입구와 납골 회랑 사이, 이후 진우의 측면 퇴로 |
| 흑풍루 감시자 | base | 북쪽 봉인문 뒤 은닉 통로에서 나타나 기록대 방향으로 이동 |

## Blocking & Props
- 진우는 석판 뒤에서 회수한 봉인 서찰을 즉시 열지 않고, 봉랍을 훼손하지 않은 채 손에 둔다.
- 혁은 동쪽 입구를 감시하며 감시자의 접근과 퇴로를 동시에 확인한다.
- 감시자는 작은 기름등을 들고 기록대 쪽으로 접근하며, 서찰을 태울 수 있는 촛불 가까이에 선다.
- 서찰은 장면 내내 진우의 손과 기록대 사이를 오가지만 봉인은 유지된다.

## Ambient / Span
약한 촛불, 재·밀랍 냄새, 납골 회랑의 긴 울림. 감시자의 발소리는 048의 일정한 간격을 이어간다. Scene 1~3에서 진우·혁은 base 상태를 유지하고 감시자의 기름등·두건·손등 화상 자국이 유지된다.

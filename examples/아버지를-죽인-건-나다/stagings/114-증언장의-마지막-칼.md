# Staging: 114-증언장의-마지막-칼

## Situation
Episode 114의 공개 증언 재개와 증언장 붕괴. 도현이 회귀의 대가를 말한 뒤 진우가 복수의 권리를 보류하지 않자, 흑풍루주가 혈인 반지와 의식장의 잔류 구조를 강제로 깨고 도현을 향해 마지막 칼을 던진다.

## Location
- `locations/흑풍루-본거지.md` — 의식장 / 침투 회랑 / 의식장 입구 처형대
- 붉은 의식석 중앙의 금 간 홈, 북쪽 침투 회랑으로 이어지는 깨진 문턱, 의식장 입구의 낮은 석단

## Cast and cited states
| Character | State | Placement |
|---|---|---|
| 서진우 | 무공-소진 | 붉은 의식석 남쪽. 부러진 검집과 평범한 단도를 곁에 두고 왼팔을 감싼다. |
| 서도현 | 처형대 | 의식장 입구의 낮은 석단 위. 손목 봉인띠가 남아 있고 청강검은 바닥에 내려놓은 상태다. |
| 흑풍루주 | 전투-의식 | 붉은 의식석 서쪽. 깨진 혈인 반지와 흑철날이 열린 의식용 지팡이를 쥔다. |
| 남궁혁 | 전장-복장 | 북쪽 침투 회랑 문턱. 백색 장검을 뽑지 않은 채 양측 병력의 진입선을 막는다. |
| 장로 대표 | 재판-상태 | 회랑 안쪽 기록판 옆. 인장 없는 죄수복과 금고리만 남아 있으며 기록판을 붙든다. |

## Situation props and fixed relations
- 도현의 회귀 대가 증언이 적힌 기록판과 사실·의도·결과 세 칸의 공개 기록이 낮은 석단과 북쪽 문턱 사이에 놓인다.
- 붉은 의식석의 끊긴 홈과 깨진 혈인 반지가 잔류 계약 구조를 이룬다.
- 흑풍루주의 흑철날은 의식용 지팡이 끝에서 한 번만 열리며, 장면 마지막의 투척 칼이 된다.
- 북문서가 병력과 흑풍루 병력은 이름 있는 병사 없이 칼끝·방패·발걸음의 비언어적 압력으로만 존재한다.

## Span and staging rules
- Scene 3은 증언 기록이 석단과 북쪽 문턱 사이에 고정된 상태에서 시작한다.
- Scene 4는 흑풍루주가 혈인 구조를 깨뜨린 뒤에도 진우·혁·장로 대표의 위치와 도현의 석단 위치를 유지한다.
- 병력은 대사를 하지 않는다. 명령과 발화는 진우·남궁혁·장로 대표·흑풍루주·도현의 이름 있는 말로만 처리한다.

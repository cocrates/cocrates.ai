# 옛 전장

## Basic Info
- Type: 폐허가 된 산악 전장
- Narrative Role: 도현의 과거, 흑풍루 병기, 진우의 봉인이 겹치는 장소.
- Role as set/stage: 무너진 성벽과 봉인석, 마른 계곡이 남아 있다.
- Key Events: 흑풍루 병기 발견, 진우 이름의 봉인 해제.

## Spatial Composition (static / physical — empty set)
- Structure/Layout: 북쪽 무너진 성문, 중앙 봉인석 계단, 남쪽 마른 계곡, 서쪽 병기 창고 폐허.
- Physical detail examples: 깨진 깃대, 검은 봉인석, 녹슨 병기함, 바람에 닳은 비문.
- Multi-facet anchors: 성문 / 봉인석 / 병기 창고.
- Sense of Scale: 탁 트였으나 폐허가 고립감을 준다.

## Sensory Environment
- Lighting / Temperature / Smell / Sound / Texture: 밝고 거친 산빛, 건조한 냉기, 녹과 먼지 냄새, 바람과 금속 마찰음, 모래 섞인 돌.

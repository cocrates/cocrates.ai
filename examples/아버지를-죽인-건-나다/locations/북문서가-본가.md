# 북문서가 본가

## Basic Info
- Type: 가문 본가·문파 복합 건축
- Narrative Role: 진우가 미래의 배신을 선점하고 실권을 장악하는 중심 무대.
- Role as set/stage: 회랑과 중정, 가주전, 장로회당이 서로 연결된 폐쇄적 본가.
- Key Events: 회귀 직후, 후계 경쟁, 폐위, 쿠데타, 최종 방어전.

## Spatial Composition (static / physical — empty set)
- Structure/Layout: 높은 담장 안에 중앙 중정이 있고 북쪽 가주전, 동쪽 장로회당, 서쪽 내당, 남쪽 외당 무기고가 배치된다.
- Physical detail examples: 검은 기와, 붉은 문서함, 중정의 오래된 회화나무, 회랑의 가문 등불.
- Multi-facet anchors: 가주전 문앞 / 가주전-회랑 접속부 / 내당 문앞 / 장로회당 표결단 / 외당 무기고 입구 / 중정 회화나무 / 중정 공개 처형대 / 중정 공개 처형대 아래 / 지하 통로 입구 / 지하 통로 대치 계단 / 지하 통로 갈라진 봉인문 / 지하 보관실.
- Internal facets: 회랑은 가주전·내당·약방을 잇는 폐쇄 동선으로, 가문 등불과 붉은 문서함이 놓인다. 내당 문앞은 회랑 서쪽 끝의 격자문과 낮은 문턱으로, 내당 출입 장부를 확인하고 안쪽을 통제하는 자리다. 약방은 내당 서편의 작은 조제 공간으로, 약 그릇을 세척·보관하는 돌 선반과 식은 약 냄새가 남는다. 지하 통로 입구 아래에는 한 사람이 몸을 낮춰 지나갈 수 있는 돌계단이 이어지고, 계단 끝의 지하 보관실은 낮은 천장과 벽면 선반, 오래된 봉인걸쇠가 남은 빈 저장 공간으로 구성된다. 중정 공개 처형대는 회화나무 남쪽의 낮은 석단과 죄수 고정쇠로 이루어져 공개 판결과 집행을 동시에 보여주는 자리다. 중정 공개 처형대 아래는 석단의 그늘과 배수 홈이 이어지는 낮은 돌바닥으로, 집행 직후 쓰러진 죄수의 상태를 확인하는 좁은 사각이다.
- Sense of Scale: 넓지만 담장과 회랑 때문에 압박감이 있다.

## Sensory Environment
- Lighting / Temperature / Smell / Sound / Texture: 중립적인 낮빛, 마른 돌의 냉기, 먹물·기름 냄새, 발걸음과 목검 소리, 거친 회랑 기둥.

## Scenes

### Scene 1 — 공개된 검은 피
**POV:** 서진우 | **Location:** 북문서가-본가 + 중정 공개 처형대 아래 | **When:** Episode 056 직후, 같은 새벽
**On stage:** 서진우, 서도현, 남궁혁
**Staging:** none

- **Situation:** 도현은 처형대 아래에 쓰러져 있고, 검은 피가 배수 홈으로 번지고 있다.
- **Beat:** 진우는 도현을 숨겨 치료하려 하지 않고, 혁에게 처형 기록을 다시 열어 사람들에게 석단 아래의 피와 검은 혈관을 보게 한다. 혁은 이름 없는 구경꾼의 웅성거림을 발화로 만들지 않고 기록판에 물증만 고정한다.
- **Turn:** 도현의 병세가 사적인 부상에서 흑풍루와 연결된 공개 의혹으로 바뀐다.
- **Function:** 검은 피를 057의 중심 증거로 승격한다.
- **Sensory-emotional:** 배수 홈을 따라 굳는 검은 피 → 진우는 처형 연극의 성공보다 아버지 몸의 붕괴가 더 빠르다는 사실을 느낀다.
- **Dialogue intent:** 진우는 공개 증거화, 혁은 기록의 명확화, 도현은 침묵과 호흡으로 버틴다.
- **Transition out:** 진우는 사람들 앞에서 도현에게 치료 가능 여부를 직접 묻고, 도현을 가주전 문앞으로 옮긴다.
- **Paragraph outline:** 1. 석단 아래의 피와 도현 상태 2. 진우의 은닉 거부 3. 혁의 기록판 재개방 4. 물증을 보는 본가의 반응 5. 검은 혈관 확인 6. 진우의 치료 질문 7. 가주전 문앞으로 이동
- **Unit budget:** dialogue 3×260 + action 3×180 + sensory 2×120 + POV 2×150 + transition 1×80 = 1,940
- **Est. length:** 1,900

### Scene 2 — 치료의 대가
**POV:** 서진우 | **Location:** 북문서가-본가 + 가주전 문앞 | **When:** Scene 1 직후, 같은 새벽
**On stage:** 서진우, 서도현, 남궁혁
**Staging:** none

- **Situation:** 도현이 가주전 문앞의 낮은 문턱에 기대고, 진우가 치료를 명령하려 한다.
- **Beat:** 진우는 의원을 부르겠다고 말하고 도현의 상처를 다시 확인한다. 도현은 치료가 시작되는 순간 진우의 봉인이 반응해 진우가 죽는다는 조건을 말한다. 진우는 그것이 협박인지 경고인지 따지지만 도현은 조건의 존재와 자신의 침묵만 반복한다.
- **Turn:** 도현을 살리는 행동이 진우의 죽음을 부를 수 있다는 선택 구조가 드러난다.
- **Function:** 부자 갈등을 병세에서 생명 교환 조건으로 확장한다.
- **Sensory-emotional:** 가주전 문턱의 차가운 돌과 도현의 검은 손등 → 진우는 아버지를 안으로 들이는 일이 자신을 사지로 들이는 것처럼 느낀다.
- **Dialogue intent:** 진우는 조건의 논리 추궁과 치료 강행, 도현은 낮은 경고와 원인 보류, 혁은 증언의 문장과 물증을 분리 기록한다.
- **Transition out:** 도현이 치료를 거부하는 대신 오른손을 내보이고, 진우는 혈관 문양을 공개 대조하기로 한다.
- **Paragraph outline:** 1. 가주전 문앞의 부상 상태 2. 진우의 치료 명령 3. 도현의 조건 증언 4. 진우의 협박 여부 추궁 5. 혁의 문장별 기록 6. 도현의 오른손 노출 7. 장로회당 표결단 대조 결정
- **Unit budget:** dialogue 4×280 + action 3×180 + sensory 2×120 + POV 2×150 + transition 1×80 = 2,280
- **Est. length:** 2,300

### Scene 3 — 같은 흔적
**POV:** 서진우 | **Location:** 북문서가-본가 + 장로회당 표결단 | **When:** Scene 2 직후, 같은 새벽
**On stage:** 서진우, 서도현, 남궁혁
**Staging:** none

- **Situation:** 장로회당 표결단 위에 처형 기록과 도현의 오른손, 진우의 봉인 확인 기록이 함께 놓인다.
- **Beat:** 혁은 공개 기록에 검은 피의 색과 혈관 변화를 적고, 진우는 도현의 손목 굴곡을 자신의 목과 왼팔 봉인 문양과 대조한다. 도현은 문양을 보자 대조를 멈추라고 하지만, 진우는 봉인의 일부가 같은 굴곡으로 이어지는 것을 확인한다.
- **Turn:** 치료 조건의 흔적이 진우 자신의 봉인과 일치하며 두 사람의 생명이 하나의 구조에 묶였다는 물증이 생긴다.
- **Function:** Episode 058 「같은 문양」의 후크를 시각적·절차적 증거로 남긴다.
- **Sensory-emotional:** 먹물 같은 혈관 선이 진우의 피부 문양과 겹친다 → 진우는 아버지의 병을 잘라 내면 자신의 목숨도 함께 잘릴 수 있음을 깨닫는다.
- **Dialogue intent:** 진우는 대조를 강행하는 짧은 명령, 혁은 기록의 객관화, 도현은 대조 중단 요구와 조건 반복.
- **Transition out:** 두 문양의 굴곡이 일치하고, 진우는 치료를 멈추지 않되 누구에게도 다음 조치를 말하지 않은 채 문양의 주인을 추적하기로 한다.
- **Paragraph outline:** 1. 표결단 위 물증 배치 2. 혁의 검은 피 기록 3. 진우의 봉인 노출 4. 도현의 대조 중단 요구 5. 혈관과 봉인의 굴곡 비교 6. 같은 흔적 확인 7. 말하지 않은 다음 추적 방향
- **Unit budget:** dialogue 3×280 + action 3×180 + sensory 2×120 + POV 2×150 + transition 1×80 = 2,020
- **Est. length:** 2,000

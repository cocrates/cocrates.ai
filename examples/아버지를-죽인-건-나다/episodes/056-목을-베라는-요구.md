## Reader Engagement (Episode Level)
### Personal Stake
진우가 칼을 실제로 밀어붙이면 아버지를 잃고, 멈추면 흑풍루와 문파 양쪽에 약점을 보인다.

## Episode Arc
진우는 공개 처형을 받아들이는 표정을 만들고, 혁에게 증인선과 칼의 각도를 맡긴다. 처형대에서 도현은 연극에 협조하지만 마지막 순간 진우의 칼을 실제로 밀어붙인다. 진우는 치명상을 피하면서 도현을 석단 아래 그늘로 떨어뜨리고, 사자의 시선을 처형대 위에 묶어 둔다. 가짜 집행 뒤 도현의 피가 검게 변하며, 연극이 감시망을 속였는지보다 도현이 이미 독에 잠식되었는지가 더 큰 문제가 된다.

## Scenes

### Scene 1 — 받아들인 처형
**POV:** 서진우 | **Location:** 북문서가-본가 + 장로회당 표결단 | **When:** Episode 055 직후, 같은 새벽
**On stage:** 서진우, 서도현, 남궁혁, 흑풍루의 사자
**Staging:** none

- **Situation:** 사자의 처형 요구가 문파의 문서 앞에 공개되었다.
- **Beat:** 진우는 거부하지 않고 공개 집행을 받아들이겠다고 말한다. 혁에게 증인선과 기록 순서를 맡기고, 사자에게 도현의 처형이 흑풍루 감시자에게 보이도록 절차를 열겠다고 통보한다.
- **Turn:** 사자는 진우가 조건을 받아들였다고 믿고 처형 시간을 정한다.
- **Function:** 처형 연극의 외부 계약을 성립시킨다.
- **Sensory-emotional:** 봉인끈이 당겨진다 → 진우는 문서 하나가 칼보다 먼저 사람을 묶는다고 느낀다.
- **Dialogue intent:** 진우는 냉정한 수용, 혁은 공개 절차의 허점 지적, 사자는 조건 반복, 도현은 침묵.
- **Transition out:** 도현이 처형대로 이동하고 진우는 칼의 각도를 정한다.
- **Paragraph outline:** 1. 사자의 조건과 문서 확인 2. 진우의 수용 선언 3. 혁에게 증인선 지시 4. 사자의 시간 확정 5. 도현의 침묵 관찰 6. 처형대 이동
- **Unit budget:** dialogue 3×260 + action 3×180 + sensory 2×120 + POV 2×150 + transition 1×80 = 1,940
- **Est. length:** 1,900

### Scene 2 — 끝까지 미는 칼
**POV:** 서진우 | **Location:** 북문서가-본가 + 중정 공개 처형대 | **When:** Scene 1 직후, 공개 집행 시각
**On stage:** 서진우, 서도현, 남궁혁, 흑풍루의 사자
**Staging:** 056-처형-연극

- **Situation:** 도현이 처형대에 묶이고 진우가 공개적으로 칼을 든다.
- **Beat:** 혁은 증인과 기록을 고정한다. 진우는 칼을 정해진 각도로 내리지만 도현이 마지막 순간 몸을 밀어 칼끝을 더 깊게 만든다. 진우가 멈추려 해도 도현은 손으로 칼을 밀어붙인다.
- **Turn:** 연극이 실제 상처로 바뀌고, 진우는 도현을 살리기 위해 칼을 비틀어 치명상을 피한 뒤 도현을 석단 아래 그늘로 떨어뜨린다.
- **Function:** 도현의 협조가 보호인지 처형 수용인지 판단할 수 없는 위험을 만들고, 사자의 시선을 위에 묶는다.
- **Sensory-emotional:** 쇠와 살이 맞부딪히는 감각 → 진우는 054의 멈춘 칼끝과 다른 현실을 맞는다.
- **Dialogue intent:** 진우는 멈추라는 짧은 명령, 혁은 절차 유지, 도현은 칼을 밀라는 낮은 침묵의 행동, 사자는 처형 확인을 재촉한다.
- **Transition out:** 도현이 석단 아래로 쓰러지고 진우는 공개적으로 집행을 완료한 것처럼 칼을 거둔다.
- **Paragraph outline:** 1. 처형대와 증인선 2. 칼을 드는 진우 3. 혁의 기록 지시 4. 도현의 갑작스러운 밀어붙임 5. 진우의 각도 변경 6. 석단 아래로 떨어진 도현 7. 쓰러진 도현과 집행 완료 연기
- **Unit budget:** dialogue 3×260 + action 3×180 + sensory 2×120 + POV 2×150 + transition 1×80 = 1,940
- **Est. length:** 1,900

### Scene 3 — 검은 피
**POV:** 서진우 | **Location:** 북문서가-본가 + 중정 공개 처형대 아래 | **When:** 가짜 집행 직후, 같은 새벽
**On stage:** 서진우, 서도현, 남궁혁, 흑풍루의 사자
**Staging:** 056-처형-연극

- **Situation:** 흑풍루의 시선 앞에서 처형이 끝난 것처럼 보였지만 도현은 석단 아래 그늘에서 숨을 쉬고 있다.
- **Beat:** 사자는 처형대 위에 남은 진우의 칼과 기록을 확인하고 물러나려 한다. 혁이 위에서 증인선을 닫는 동안 진우가 석단 아래로 내려가 도현의 상처를 누른다. 상처에서 검은 피가 나오고 오른손 혈관이 검게 솟는다.
- **Turn:** 가짜 처형은 감시망을 속였지만, 도현이 흑풍루의 독에 중독되어 있다는 새로운 증거가 공개된다.
- **Function:** 057의 검은 피 폭로를 직접 후크로 만든다.
- **Sensory-emotional:** 검은 피가 돌바닥과 배수 홈으로 번진다 → 진우는 연극이 끝난 뒤에도 도현의 몸이 진짜로 무너지고 있음을 본다.
- **Dialogue intent:** 사자는 조건 이행을 확인하는 낮은 말, 혁은 철수와 증거 보존을 지시, 진우는 도현의 상태를 묻고, 도현은 대답하지 못한다.
- **Transition out:** 사자가 물러난 뒤 검은 피가 마지막으로 번지고 진우는 도현을 다시 공개 심문해야 한다.
- **Paragraph outline:** 1. 처형 완료를 확인하는 사자 2. 혁의 증인선 폐쇄 3. 진우가 석단 아래에서 도현 상처를 압박 4. 검은 피와 혈관 변화 5. 사자의 조건 확인 실패 6. 도현의 침묵 7. 돌바닥과 배수 홈으로 번지는 피
- **Unit budget:** dialogue 4×280 + action 3×180 + sensory 2×120 + POV 2×150 + transition 1×80 = 2,280
- **Est. length:** 2,300

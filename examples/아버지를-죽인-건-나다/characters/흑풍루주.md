# 흑풍루주

## Basic Info
- Role: 흑풍루의 수장·최종 적
- Core Drive: 진우를 완성된 후계자로 만들고 자신의 실패를 증명한다.
- Central Conflict: 도현에게서 빼앗은 아이를 괴물로 만든 책임을 인정하지 않는다.
- Arc Direction: 보이지 않는 설계자에서 공개 심판의 대상.

## Appearance & Behavior Traits
- 외형(Appearance): 50대, 검은 장발과 희고 매끈한 얼굴, 눈동자 가장자리에 붉은 반점이 있다. 체격은 가늘지만 자세가 완벽하다.
- 습관/거동(Behavior): 상대의 이름 대신 계약 조건을 읽고, 손톱으로 탁자를 세 번 두드린다.
- 말투/표현(Voice): 정중한 존대와 교육자의 어조. 분노할수록 상대의 어린 시절 호칭을 사용한다.
- 반복되는 단서(Signature cues): 붉은 눈 가장자리, 세 번 두드리는 손톱, 흑색 혈인.

## Reference models (appearance + equipment states)
- base: 검은 무늬 장포, 붉은 혈인 반지, 은빛 목걸이, 칼 대신 짧은 의식용 지팡이를 착용한다.
- 전투-의식: 같은 얼굴에 팔과 목에 붉은 혈맥 문양이 드러나며, 혈인 반지가 검게 변한다. 지팡이 끝에 짧은 흑철날이 열린다.

## Key Relationships
- 서도현 ↔ 흑풍루주: 같은 사부 아래에서 갈라진 옛 동문.
- 서진우 ↔ 흑풍루주: 계약과 실험으로 연결된 후계 후보와 주인.

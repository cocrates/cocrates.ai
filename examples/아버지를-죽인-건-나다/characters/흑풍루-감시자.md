# 흑풍루 감시자

## Basic Info
- Role: 흑풍루 납골당 감시자·서찰 회수 담당
- Core Drive: 기록과 서찰의 이동을 감추고 조직의 보관 규칙을 지킨다.
- Central Conflict: 도현의 과거를 알고 있지만, 진우에게 진실을 말하면 자신이 지켜 온 보관망이 무너진다.
- Arc Direction: 침묵하는 회수자 → 도현의 옛 부하임을 암시하는 제한적 증언자.

## Appearance & Behavior Traits
- Appearance: 30대 후반, 길고 마른 체격, 왼쪽 손등에 납골당 촛불에 데인 흰 자국, 얼굴을 반쯤 가리는 검은 두건을 쓴다.
- Behavior: 문서보다 출구를 먼저 확인하고, 발소리를 일정한 간격으로 끊는다. 위급할 때 서찰의 봉랍을 불에 가까이 댄다.
- Voice: 낮고 마른 존대. 질문에 답하지 않고 확인된 사실 한 조각만 남긴다.
- Signature cues: 왼쪽 손등의 흰 화상 자국, 촛불을 향하는 손, 일정한 발소리.

## Reference models (appearance + equipment states)
- base: 검은 두건, 검은 장삼, 회색 손등 보호대, 작은 기름등을 지닌다. 노출 무기는 없다.

## Key Relationships
- 서진우 ↔ 흑풍루 감시자: 서찰을 두고 맞서는 추적자와 회수자.
- 서도현 ↔ 흑풍루 감시자: 도현의 과거 명령과 납골당 보관 규칙을 알고 있는 옛 조직 관계.
- 흑풍루 ↔ 흑풍루 감시자: 명령의 전체 목적은 모른 채 기록과 서찰의 이동만 관리하는 하위 실무자.

# 백무진

## Basic Info
- Role: 북문서가 외당 제자·호송 실무자
- Core Drive: 자신과 외당 제자들이 장로회와 흑풍루의 소모품이 되지 않도록 살아남을 통로를 확보한다.
- Central Conflict: 진우의 명령을 따르면 내당의 압박에서 벗어날 수 있지만, 동료를 팔아넘긴 사람으로 낙인찍힌다.
- Arc Direction: 계산적인 생존자 → 조건을 공개한 첫 내부 협력자.

## Appearance & Behavior Traits
- 외형(Appearance): 20대 후반, 넓은 턱과 다부진 체격, 짧은 갈색 머리, 오른쪽 손등에 오래된 칼자국이 있다.
- 습관/거동(Behavior): 대답하기 전 출입구와 사람 수를 세고, 불리한 상황에서도 손을 허리 아래로 내리지 않는다.
- 말투/표현(Voice): 짧고 거친 반말. 책임을 인정할 때는 변명 대신 조건을 먼저 제시한다.
- 반복되는 단서(Signature cues): 짧은 갈색 머리, 오른손등 칼자국, 출입구를 먼저 확인하는 시선.

## Reference models (appearance + equipment states)
- base: 짙은 회색 외당 무복, 가죽 손목보호대, 검은 호송검, 외당 패찰을 착용한다. 오른손등 칼자국과 다부진 체격은 고정 식별점이다.

## Key Relationships
- 서진우 ↔ 백무진: 진우가 공개 심문으로 선택을 강요하는 대상이자 첫 내부 협력 후보.
- 윤태석 ↔ 백무진: 서로 다른 당의 실무자. 윤태석의 숨은 목적을 눈치채고도 거래를 위해 침묵한다.
- 장로 대표 ↔ 백무진: 외당 인력의 책임을 장로회 절차 아래 묶으려는 상하 관계.

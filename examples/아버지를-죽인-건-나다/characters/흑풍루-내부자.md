# 흑풍루 내부자

## Basic Info
- Role: 흑풍루 내부 인계망의 실무자·거래 제안자
- Core Drive: 조직의 후계자 제작 계획에서 자신과 거래선의 생존 몫을 확보한다.
- Central Conflict: 아이를 물건으로 넘기는 인계망을 유지해야 살 수 있지만, 오래된 기록과 다음 거래를 외부에 흘려 판을 바꾸려 한다.
- Arc Direction: 익명의 내부 거래자 → 흑풍루 후계자 제작 구조를 증언하는 잠정 협력자.

## Appearance & Behavior Traits
- 외형(Appearance): 30대 후반, 마른 체격, 얼굴 왼쪽에 얕은 칼자국, 검은 소매와 낡은 회색 장갑을 착용한다.
- 습관/거동(Behavior): 상대의 얼굴보다 손과 문서를 먼저 확인한다. 거래 조건을 말할 때 검은 장갑의 손가락을 한 번 접는다.
- 말투/표현(Voice): 낮고 건조한 존대. 이름과 감정을 거의 부르지 않고 조건과 기한으로 말한다.
- 반복되는 단서(Signature cues): 검은 소매, 회색 장갑, 접힌 손가락, 검은 삼중선 표식.

## Reference models (appearance + equipment states)
- base: 검은 소매의 무복, 낡은 회색 장갑, 허리의 짧은 칼, 검은 삼중선이 찍힌 납작한 인계패를 지닌다.

## Key Relationships
- 서진우 ↔ 흑풍루 내부자: 아이와 다음 회합 장소를 맞바꾸려는 추적자와 거래 상대.
- 흑풍루주 ↔ 흑풍루 내부자: 명령을 분산해 전달하는 상하 관계. 내부자는 최종 의도와 전체 조직도를 알지 못한다.
- 봉인된 또 다른 아이 ↔ 흑풍루 내부자: 아이를 후계자 제작망의 다음 단계로 넘긴 인계자와 생존자.
- 서진우의 어머니 ↔ 흑풍루 내부자: 이동 행렬의 인계 실무 중 감옥 상태를 직접 확인한 목격 관계. 정확한 목적지와 현재 상태는 모른다.

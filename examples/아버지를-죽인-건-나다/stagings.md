# Staging Index: 아버지를 죽인 건 나다, 회귀해서 친다

- **007-장로-표결-압박**: Episode 007 「후계자의 자리」의 장로회 후계 표결. 진우·도현·장로 대표·백무진·윤태석의 위치와 명부·호송 장표·색인 쪽지를 Scene 1~2에 걸쳐 잠근다.
- **009-불탄-기록-추적**: Episode 009 「불탄 기록」의 불탄 기록 추적과 가환 대면. 진우·가환의 상태, 기록 조각·약 그릇 조각, 회랑에서 가주전 문앞으로 이어지는 동선을 Scene 2~3에 걸쳐 잠근다.
- **010-도현의-약상자**: Episode 010 「가환의 침묵」의 가주전 문앞 약 교체 감시. 진우·가환·도현의 위치와 약 그릇 조각·약상자·두 약 봉지의 상태를 Scene 1~2에 걸쳐 잠근다.

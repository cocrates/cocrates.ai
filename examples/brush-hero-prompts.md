### 31. 그림책 작성 스킬 3가지 보완 요청
> **사용자**: "그림책 작성 스킬에 다음을 보완해줘. 1. 정의 단계에서 챕터의 개수, 챕터당 페이지수가 정의되도록 해줘. 2. 페이지 이미지가 생성될 때, 페이지 텍스트도 같이 렌더링 되도록 해줘. 3. 이미지 yaml 명세에 대한 검토 승인이 없이 자동으로 이미지가 생성되지 않도록 해줘. 사용자 승인을 강화해줘."

**에이전트**: picture-book-authoring 스킬 파일(SKILL.md)을 수정하여 3가지 보완 사항을 반영:
1. **챕터 구조 정의**: overview.md 템플릿에 `챕터 수`, `챕터당 페이지 수` 필드 추가. G1 승인 게이트에 챕터 구조 확인 항목 추가.
2. **페이지 텍스트 렌더링**: Phase 1 프롬프트 패턴에 `TEXT OVERLAY` 섹션 추가. 렌더링 텍스트를 이미지에 직접 렌더링하는 설계 규칙 6개 추가(키 대사 강조, 나레이션 배치, 얼굴 가리지 않기 등).
3. **YAML 승인 강화**: Phase 0/1에 "명시적 사용자 승인 대기" 규칙 강화. Dialogue Rules에 "모든 이미지 YAML에 대해 개별 승인 필수, 일괄 자동 생성 금지" rule 3 추가. Prohibitions에 "배치 자동 생성 금지", "각 YAML에 대해 개별 승인 필수" 추가.

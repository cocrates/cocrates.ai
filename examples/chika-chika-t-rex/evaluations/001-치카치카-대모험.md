## 6. Persona Checks

### 아이 관점 (5세 남아)
- 재미도: ⭐⭐⭐⭐⭐ — 공룡 변신 + 액션 + 몬스터 퇴치, 5세 남아의 관심사를 정확히 타겟팅.
- 이해도: ⭐⭐⭐⭐⭐ — 그림+짧은 텍스트로 스토리 라인 명확. 양치 동작이 액션이라 직관적.
- 페이지 넘기고 싶은가: ⭐⭐⭐⭐⭐ — 매 페이지 액션+훅으로 다음 장 강한 유인.
- 피드백: 티라노 변신, 칫솔 검 액션, 몬스터가 작아지는 재미 — 5세 남아가 좋아할 요소로 가득.

### 부모 관점
- 가치/공유 의향: ⭐⭐⭐⭐⭐ — 양치질을 게임/모험으로 바꿔주는 콘셉트. 아이와 함께 읽으며 롤플레이 가능.
- 안전성: ⭐⭐⭐⭐⭐ — 폭력적이지 않음. 몬스터가 다치지 않고 작아져서 사라짐. 치과 공포 유발 요소 없음.
- 설교 과잉 없음: ⭐⭐⭐⭐⭐ — 교훈을 직접 말하지 않음. 모험의 결과로 양치질의 즐거움을 보여줌.
- 피드백: 양치질 거부하는 아이에게 "티라노가 되어 볼래?"라는 접근법 제시 — 실생활에 바로 활용 가능.

### 평론가 관점
- 스토리 완결성: ⭐⭐⭐⭐ — 시작(투정)→변신→갈등→액션→클라이맥스→해결→복귀의 완전한 구조. 10페이지에 잘 압축됨.
- 캐릭터 매력: ⭐⭐⭐⭐ — 티라노 변신이라는 강력한 캐릭터 후크. 충균 몬스터의 코믹 악당 밸런스 좋음.
- 텍스트–이미지 협응: ⭐⭐⭐⭐ — 텍스트는 액션 대사+효과음, 이미지는 배경+액션 장면. 협응 잘 됨.
- 피드백: 10페이지라는 제약을 고려할 때 매우 효율적인 스토리텔링. 양치 동작을 액션으로 재해석한 점이 참신.

### 일러스트 전문가 관점
- 참조 모델 일관성: ⭐⭐⭐⭐ — 캐릭터/장소 state 정의 명확. 충균 몬스터 중간 크기(P4~P5)는 페이지 가이드로 처리 가능.
- 장면 명확성: ⭐⭐⭐⭐⭐ — 각 페이지 position/view가 구체적이고 "무엇이 보이는가" 기준으로 명확.
- 페이지 프레이밍: ⭐⭐⭐⭐ — position/view가 잘 정의되어 일관된 화면 구성 가능.
- 텍스트 시각 효과 가이드: ⚠️ — anchor area 위치는 Stage ④ YAML에서 구체화 필요. 의성어/감탄사의 시각적 강조(폰트 크기, 색상) 계획은 좋음.

#### 텍스트 오버레이 가이드 (Stage ④ YAML 반영용)

**Reading order anchor plan:**
- 기본: 상단(내레이션/설명) → 하단(대사/효과음) 순서. 우→좌 텍스트는 한국어 특성상 좌→우 정렬.
- 페이지별 텍스트 영역 맵:
  - P0: 중앙 대형 타이틀
  - P1~P2: 상단 내레이션 영역, 하단 대사 영역(말풍선 권장)
  - P3~P7: 액션 페이지 — 대사는 하단/우측 말풍선, 의성어는 액션 궤적 근처에 크게 배치
  - P8~P9: 상단 내레이션, 하단 대사

**TextBox list (권장):**
- 내레이션: 중간 크기 둥근 고딕체, 따뜻한 흰색 바탕에 진한 글자, 부드러운 그림자
- 대사: 굵은 둥근 고딕체, 캐릭터 포인트 색상(티라노=초록 계열, 몬스터=보라 계열), 진한 외곽선
- 의성어/액션: 가장 크게 + 굵게, 액션 방향에 맞춰 기울임, 글로우/아웃라인 효과, 형광색(하양/노랑/파랑)

**Key word emphasis 계획:**
- "치카치카" — 가장 핵심 키워드, 크고 굵게, 노랑/하양 글로우
- "샥샥" — 파랑 계열, 날카로운 폰트 효과
- "크아아아" — 빨강/주황 계열, 포효 느낌

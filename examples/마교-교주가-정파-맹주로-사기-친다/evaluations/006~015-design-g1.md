# G1: Target Reader

## 칭찬 (Praise)

- **006 ep001 남궁휘 POV 인서트** — 파트 오프닝이 '악당의 공포'부터 보여준다. 독자는 005의 쪽지 수령 장면(미소가 사라지고 다시 씌움)을 남궁휘의 내부 시점으로 함께 겪으며 '무엇을 할 것인가'를 질문하게 된다. 사이다 장르의 '고민 2화 금지'(overview 검증기준 1)를 즉시 대응(숙청+2차 명령)으로 지킴.
- **007 전투의 '비용 있는 승리'** — 회복기 한계(옆구리 통증·소매 찢김, 007 S3)와 천마위압 1회 사용(007 S4, 머리 울림)으로 완벽승을 피한다. '잡는 자 vs 죽이는 자'의 차이가 장면으로 드러나며(007 S4 "죽이고 싶지 않아서 묶는다"), 생포가 다음 수(008 심문)를 자연스럽게 연다.
- **011→012 연속 2화 카타르시스** — "증거 따위 필요 없고…"(011 S5) → "주먹으로 보여드리지, 형님"(011 S6) → "직감이 증거요, 주먹이 명분이지"(012 S4) + 다리 분질러. 명대사가 '실행 순간'에 완결되므로 독자가 기다린 보상이 물리적으로 지불된다. 원안 명대사를 희소 배치(011~012)한 것은 장르 클리셰 남발 방지에 정확.
- **클로징 훅 체인** — 008 "노의원." → 009 약방 방문 / 009 "장로님들 앞에 가면 되겠네" → 010 대청 / 011 "주먹으로…" → 012 응전 / 012 "가회는 계속됩니다" → 013 장부 / 013 침묵 → 014 질문 / 015 박수. 전 화가 '한 줄 대사+이미지' 훅으로 다음 화 오프닝을 직접 여는 구조 — 10화 내내 체인이 끊기지 않음.
- **'내 사람' payoff의 승격 구조** — 설향 비트가 006 S3(문틈) → 007 S5(잠든 실루엣, 무음 규칙 성공) → 009 S5(약 확인) → 014 S4(위상 공식화) → 015 S4(감사·안도)로 '보호 → 규칙 → 위상 → 안도'의 계단을 오른다. 냉혈한 정치적 장면 사이의 유일한 따뜻한 축.
- **015 S6 '정중한 박수'** — 다정한 얼굴이 가장 위협적인 파트 클로징. 진심/조롱/경고의 3중 해석을 남긴 채 화를 닫는 것이 '다음 그림자(남궁혁)' 훅으로 강력하다.

## 결함 (Defects)

- **(High) 가회 아크 4화 연속 '설향 부재' — 온기 축이 꺼진다.**
  - Evidence: 010~013 (가회 아크 전 구간)에 설향 장면 0회. 006/007/009에서 유지되던 '내 사람' 온기가 010~013의 대청 정치(같은 장소·같은 6인·같은 증거 토론) 4화 동안 완전히 소거된 뒤 014에서야 복귀.
  - Suggested fix: 012 S6 "가회는 계속됩니다" 전후에 취운각에서 대청 소란을 듣는 설향 1컷(문풍지·촉 켜진 등불)을 삽입 — 독자가 정치 회의 사이에 '보호 대상이 무사한지'를 확인하며 숨을 고르는 비트.
- **(Med) 유쾌/개그 비트가 10화에 1개뿐 — 장르 계약(통쾌·유쾌) 이탈 위험.**
  - Evidence: overview 톤 "통쾌하고 유쾌하며 시원시원함", 개그. 그러나 006~015에서 가벼운 비트는 014 S3(하인 아첨) 단 하나. 006~009는 조용한 준비/심문, 010~013은 절차·침묵, 014~015는 정리 — 전 파트가 '무거운 톤'으로만 이어짐.
  - Suggested fix: 011 S6 휘의 폭발("증거가 뭐가 어쨌다는 거야, 조작이지!")을 슬랩스틱에 가깝게(망나니 시절 폭언의 우스꽝스러움), 009 S1~S2 노의원의 '과한 다정함'에 블랙코미디 텐션, 014 S3 하인 아첨 장면 확대.
- **(Med) 명대사 2개가 한 장면(011 S5)에 몰림 — 012 완결형의 임팩트 분산.**
  - Evidence: 011 S5에 "증거 따위 필요 없고, 네놈이 범인인 걸 내가 안다" + "직감이 증거요"가 동시 발화. '증거 따위 필요 없고'와 '직감이 증거요'는 사실상 같은 메시지의 이중주 — 독자에게 두 줄이 하나로 흡수되고, 012에서 진짜 명대사가 완결될 때의 신선함이 깎인다.
  - Suggested fix: 011은 "증거 따위 필요 없고…"만 발화, "직감이 증거요"는 012 S4의 완결형("직감이 증거요, 주먹이 명분이지")으로만 유보.
- **(Med) 남궁휘의 화면 부재(007~009) — 응징 대상의 존재감 하락.**
  - Evidence: 006 ep001 이후 휘는 007(언급)~008(언급)~009(언급)로 사라지고, 독자가 010 가회에서 '미워할 대상'을 재확인해야 함. 사이다 독자는 악당이 화면에 자주 나와 미움이 쌓여야 응징이 통쾌하다.
  - Suggested fix: 008 ep002 자백 중 휘의 '다정한 형' 보이스오버/회상 1컷("태의야, 형이 걱정돼서 그래") 또는 009 말미 '휘가 김충 실종을 눈치채는' 미니 공포 장면.
- **(Med) 014 S6 "잘 마무리했구나"가 015 S6 박수를 예고 — 파트 클로징 훅의 임팩트 소모.**
  - Evidence: 014 S6 남궁혁이 이미 다정한 관찰 대사를 소비함. 015 S6의 '정중한 박수'가 014에서 맛보기된 '다정한 혁'의 반복으로 느껴질 위험.
  - Suggested fix: 014 S6은 혁의 대사 없이 '미소 + 고개 숙임'만, 박수는 015 S6에서 첫 등장으로 (희소성 유지).
- **(Med) 006이 '준비 화'로 느려질 수 있음.**
  - Evidence: 005 클로징 "시작이다"의 모멘텀을 받는 006인데, ep002(아침의 소문 — 설향·노의원 시드)와 ep003(밤의 감시·몸 점검)이 모두 액션 없는 관찰·준비. 실제 격돌(전투)은 007까지 기다려야 함.
  - Suggested fix: 006 ep002에 미니 페이오프 하나 — 예: 소문이 실제로 동원을 움직이고(휘가 문앞 묶인 자를 처리하는 장면을 하인 보고로), '준비'가 아니라 '보이는 전진'이 되도록.
- **(Med) 013 갈등 해소 과속 — 저항이 약하면 승리가 싱거워진다.**
  - Evidence: 012의 폭발(다리) 직후 장로 격분(013 ep001) → 장부 대조(013 ep002) → 규칙 선언 + 남궁경 지팡이 놓음 + 아버지 침묵(013 ep003)이 한 화 안에 완결. '절차의 화신' 남궁경이 이중장부 하나로 즉시 굴복.
  - Suggested fix: 남궁경의 종결을 '허락'이 아닌 '유보'(이중장부는 확인했으나 처벌 절차는 별도로 하겠다)로 남겨 Part 3의 무게를 예약.
- **(Low) 014~015 '아버지 침묵' 혼잣말 이중 반복.**
  - Evidence: 014 S6 "아버지는 침묵한다. 그게, 남은 질문이다." / 015 S5 "아버지는 여전히 침묵하신다." — 같은 메시지를 두 화에 걸쳐 같은 톤(혼잣말·낮은 목소리)으로 반복.
  - Suggested fix: 015는 빈 주좌 위에 놓인 아버지의 물건(따뜻한 차 그릇 하나) 같은 '침묵의 이미지'로 대체.
- **(Low) 006 클로징 ↔ 007 오프닝 이미지 중첩.**
  - Evidence: 006 S6 "김충의 그림자가 취운각 쪽으로 향한다" → 007 S1 "김충이 취운각 담장에 손을 얹는다". 두 화 연속 '그림자 → 접근'의 같은 장면 전개 — 데자뷔 위험.
  - Suggested fix: 007 S1을 이미 '담장 안(안마당 → 문가)'에서 시작, 006 클로징은 '취운각으로 향하는 발걸음'까지로 조정.

## 독자 욕구 관점 우선순위

1. **온기 축 복구 (High #설향)** — 10화 중 4화 정치 공백은 사이다 독자의 '유일한 인간적 축'을 끊는다. 가회 아크 내 1컷이면 충분하나 반드시 필요.
2. **유쾌 비트 보강 (Med #개그)** — 통쾌×개그 장르 계약의 '웃음' 몫이 이 파트에서 사라짐. 011/009/014에 코믹 텐션.
3. **카타르시스 정밀화 (Med #명대사 분산, #014→015 예고)** — 명대사와 파트 클로징의 희소성을 지켜야 011~012·015가 '기다린 보상'으로 남는다.
4. **응징 대상의 재등장 (Med #휘 부재)** — 악당을 계속 화면에 올려 미움을 재충전.

# G1: Reader-Editor

## 칭찬 (Praise)

- **훅 체인 100% 연결** — 006(김충 명령) → 007(손) → 008(자백) → 009(처방전) → 010(가회) → 011(증거) → 012(주먹) → 013(장부) → 014(침묵) → 015(박수). 모든 화 오프닝이 이전 클로징을 즉시 이행, 방치된 훅 0건. (gate 검증과 일치)
- **POV 인서트 예산 준수(≤2) 및 배치** — 006 ep001 남궁휘(전환점), 007 ep001 김충(전환점). 008 자백을 태의 고정 POV로 유지한 것은 심문장의 '권력 구도'(묻는 자만 내면이 보임)를 지킨 옳은 선택.
- **화 단위 정보 예산 라벨 일관** — Exposition Budget이 화마다 명시(008/013 '중간', 나머지 '낮음'), 정보 폭탄 화가 설계 단계에서 격리됨. 008의 자백·013의 장부 대조는 '중간'으로 관리 중.
- **명대사 희소 관리** — 원안 3개 중 "직감이 증거요, 주먹이 명분이지"만 011~012에 분리 발화, 나머지 2개("정파 맹주 아들인데"·"협은 포장지")는 Hold 유지. 010 이전에는 명대사 0회 — 파트 내 희소성 유지.
- **정보의 '재전달' 설계** — 독 유통 구조가 008(자백) → 011(대청 공개) → 013(장부 대조)의 3단계로 재제시되어, 화 단위 독립성(한 화만 봐도 이해 가능)을 보장. 파트 단위 미열람 독자의 손실을 최소화.

## 결함 (Defects)

- **(High) '심문→자백→도구화' 패턴 3연속 (005/008/009) — 독자 피로.**
  - Evidence: 005(잡졸 "배달만" 자백) → 008(김충: 폭력 없이 정보 압박 → 자백 → "살려서 쓰기") → 009(노의원: 폭력 없이 정보 압박 → 자백 → "감시·도구"). 008과 009는 구조가 쌍둥이 — 같은 화 내 뼈대(대치→균열→자백→자산화)가 두 번 반복되고, 두 인물 모두 '감금/감시'로 동일 배치.
  - Suggested fix: 009를 '자백 드라마'가 아니라 '문서 드라마'로 재편 — 노의원의 무너짐을 1장면(009 ep001 S2)에 압축하고, 나머지를 처방전·복용 이력(기록의 무게)과 '설향 약 안전'의 장면으로 채움. 자백의 결과물(증거)이 자백 행위보다 앞서도록.
- **(Med) 008↔011 정보 이중 전달 — 같은 내용이 자백과 공개로 두 번.**
  - Evidence: 독 유통 구조(명령자·전달자·조제자)가 008 S3(자백)에서 처음 드러나고 011 S2(대청 명명)에서 재공개. 밀거래 물품(장부에 없는 돈)도 008 S4 → 011 → 013에서 삼중 노출.
  - Suggested fix: 011 S2의 사슬 명명을 '이미 들은 것'으로 압축(김충 자백을 회상 1줄로), 독자가 008의 기억을 통해 대청 장면을 해석하게 함. 재전달은 013 장부 대조 하나로 충분.
- **(Med) 014↔015 기능 중복 — '정리 화'가 2연속.**
  - Evidence: 014 ep001(휘 유폐·노의원 치료·김충 감금 유지)과 015 ep001(폐출 수순·배치 확인)이 '배치 확인'으로 겹치고, 아버지 침묵 클로징도 014 S6·015 S5로 이중. 파트 데누망이 2화 모두 같은 성격(정리)이라 경계가 모호.
  - Suggested fix: 014는 '온기·기류'(설향 위상·하인 아첨)에 집중하고, 015의 폐출을 '새로운 결정'으로(독자가 014에서 모른 채) 제시해 정보 신선도 유지. 침묵 클로징은 014 하나로 통일.
- **(Med) 신규 독자(Part 1 미열람) 복습 부담 — 006 오프닝이 005 결과에 무전제 의존.**
  - Evidence: 006 ep001 S1은 '묶인 암살자 2인 + "곧 찾아가마" 쪽지'를 받는 남궁휘로 시작하지만, 이 풍경이 무엇인지(005에서 태의가 역공해 돌려보낸 것)를 설명하는 장치가 없음. 파트 단위로 진입하는 독자는 "왜 두 사람이 묶여 있고 남궁휘가 두려워하는가"를 추론해야 함.
  - Suggested fix: 006 S1의 하인 보고 대사에 문맥 복구 1줄("동원 문앞에, 입을 막은 채 묶여 있던 자들이… 쪽지가 함께였습니다")을 포함 — 오프닝 훅을 유지하면서 복습 비용 0.
- **(Med) 김충 POV 1회 한정 — 008 자백의 '프로→생존자' 내면 전환 배제.**
  - Evidence: 008의 모든 장면이 태의 POV. 김충이 '죽음을 준비하는 마음' → '살길을 찾는 마음'으로 전환하는 심리적 무대가 태의의 얼굴 뒤에서만 일어나면 자백이 '사실의 나열'로 읽힐 위험.

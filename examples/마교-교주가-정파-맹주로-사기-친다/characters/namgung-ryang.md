# 남궁량 (南宮良)

## 기본 정보
- Role: 조연 (Part 2~) — 남궁세가 살림 장로, 장부·재물 관리
- Core Drive: 세가 재물의 건전성을 장부로 관리한다.
- Central Conflict: 남궁휘의 밀거래 횡령을 이중장부로 가려진 채 감찰하지 못했다는 자책. 태의가 장부 대조를 요구하며 휘의 횡령을 드러낼 때, 진실 확인 후 태의 편으로 기울기 시작.
- Arc Direction: flat→positive — 자책 → 진실 확인 → 태의의 새 질서에 협력.

## 외형 및 거동 특징
- 외형(Appearance): 60대 초반. 단정한 진회색 장로복, 검은 관모. 마르고 키가 큼.
- 습관/거동(Behavior): 장부를 가까이 들여다보는 습관. 숫자를 말할 때 눈을 감고 기억을 되짚음. 손이 마르고 깔끔함.
- 말투/표현(Voice): 침착하고 숫자 중심 — "장부는 거짓말하지 않습니다. 다만… 제가 본 것은 이중 장부였을 뿐." 자책할 때 목소리가 낮아짐.
- 반복되는 단서(Signature cues): 장부를 품에 안는 습관, '장부'라는 단어, 눈을 감고 숫자를 되짚는 버릇.

## Reference models
- base: 진회색 장로복, 검은 관모, 마른 체구, 장부(책)를 들고 다님.

## 주요 인물과의 관계
- 남궁태의 ↔ 남궁량: 태의가 008 자백(세가 재산 빼돌리기)을 받아낸 뒤 장부 대조를 요구. 량은 처음엔 거부하다가 진실을 확인하고 협력.
- 남궁휘 ↔ 남궁량: 휘가 이중장부를 꾸며 량을 속여 옴 — 량이 가장 수치심을 느끼는 대상.
- 남궁경 ↔ 남궁량: 원로 동료. 경의 절차주의와 량의 장부 사실주의가 가회에서 보완 관계.

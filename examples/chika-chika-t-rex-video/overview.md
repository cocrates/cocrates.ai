# 치카치카 티라노 (영상)

## Basic info
- Title: 치카치카 티라노
- Genre / form: 애니메이션 / 그림책 스토리텔링 영상
- Target audience: 3~6세 (주 시청자: 5세)
- Tone / mood: 유쾌하고 신나는 모험 액션, 약간의 코믹
- Production mode: **Short** (단일 세그먼트)
- Expected length: ~3~5분 이내
- Clip count (예상): 15~20클립 (스토리 비트 단위 분할)

## Intent / message summary
양치질하기 싫어하는 꼬마가 칫솔을 들자 티라노사우루스로 변신해 치카치카 왕국으로 모험을 떠난다. 충균 몬스터에게 더럽혀진 이빨 성을 구하기 위해 칫솔 검으로 위아래, 앞뒤, 안쪽까지 양치 액션을 펼치고, 마지막 물 헹굼으로 몬스터를 물리친다. 현실로 돌아와 거울 속 반짝이는 이빨을 확인하며 양치질의 즐거움을 깨닫는다.

**영상 전달 방식:** 그림책 페이지 이미지를 그대로 사용하지 않고, 캐릭터/장소 참조 이미지를 기반으로 각 스토리 비트별로 새로운 키 이미지와 모션 클립을 제작하여 하나의 애니메이션 스토리텔링 영상으로 구성한다. 나레이션(엄마 목소리)이 이야기를 이끌고, 등장인물(주인공, 충균 몬스터)의 대사가 번갈아 나오며, BGM과 효과음이 분위기를 살린다.

## Style direction
- **Visual:** 그림책 원작의 수채화 스타일 계승 — 따뜻하고 부드러운 파스텔 톤. 공룡은 초록/파랑 계열, 몬스터는 보라/검정 계열, 왕국은 화이트/핑크/민트. 부드러운 윤곽선, 귀엽고 동글동글한 형태.
- **Audio:**
  - Voice: 한국어 TTS — **엄마**(내레이터), **주인공**(꼬마/티라노 대사), **충균 몬스터**(악당 대사) — 3개 목소리
  - BGM: 모험/액션 장르에 맞는 경쾌하고 신나는 배경음악
  - SFX: 변신 반짝임, 칫솔 검 액션, 몬스터 효과 등
- References: `chika-chika-t-rex/images/` 아래의 기존 참조 이미지 활용

## Constraints
- Taboos: 치과/이빨 치료에 대한 공포 유발 금지, 너무 무서운 악당 금지
- Out of scope: 실제 치과 치료 과정, 이빨이 빠지는 장면
- Technical budget: motion video clips < ~10s; TTS-led clips may be ~30s

## Validation Criteria

| Criterion | How to verify |
|-----------|---------------|
| 타겟 연령(3~6세)이 영상을 따라갈 수 있다 | 각 클립의 시청 이해 시간이 길이 이내 |
| 아이가 양치질을 긍정적으로 느끼게 한다 | 마지막 클립에서 양치질을 하고 싶은 마음이 들도록 구성 |
| 양치질의 올바른 방법이 자연스럽게 녹아 있다 | 위아래, 앞뒤, 안쪽, 헹굼 4가지 동작이 영상 액션에 모두 포함됨 |
| 그림책 원작 스토리와 캐릭터를 충실히 따름 | 원작 episode의 스토리 비트, 대사, 캐릭터 성격이 유지됨 |
| 3개 목소리(엄마/주인공/몬스터)가 명확히 구분된다 | 시청자가 목소리만으로 화자를 식별 가능 |
| BGM/SFX가 이야기 흐름을 돕고 방해하지 않음 | 대사가 묻히지 않고, 장면 전환에 효과음이 적절히 사용됨 |
| 금기사항 위반 없음 | 치과 공포, 이빨 빠짐, 너무 무서운 악당 없음 |

# Episode 022: 벽 속의 봉투

## Summary
서윤은 어머니의 옛집 안쪽 벽 틈에서 봉투를 꺼내기 전, 120통과 종이·봉인·번호를 대조한다. 벽 속 봉투는 120통과 다른 날짜의 봉투이며, 받는 사람 칸이 비어 있다. 서윤은 봉투를 꺼내지만 열지 않고, 마지막 통의 위치와 수신인 공백이 연결되어 있음을 확인한다.

## Purpose
벽 속 봉투를 실제 물건으로 꺼내고, 마지막 통과 다른 수신인 공백을 연결한다.

## Reader Engagement
### Personal Stake
벽 속 봉투가 자신에게 오지 않은 편지라면 서윤의 읽기는 또 다른 사람의 시간을 침범하게 된다.
### Opening Question
벽 속 봉투는 왜 상자 밖에 숨겨졌을까?
### Stakes
봉투를 열면 마지막 통의 답을 앞당길 수 있고, 닫아 두면 숨겨진 수신인의 흔적을 보존할 수 있다.

## Episode Arc
서윤은 벽의 틈을 손상시키지 않고 봉투를 꺼낸다. 봉투에는 120통과 다른 날짜, 비어 있는 수신인 칸이 있다. 서윤은 두 봉투를 나란히 보존하고 열지 않은 채, 120통을 읽을 준비를 한다.

## Scenes

### Scene 1 — 벽을 손상시키지 않기
**POV:** 한서윤 | **Location:** 어머니의-옛집 + 안쪽 벽의 틈 | **When:** 021화 다음 날 오전
**On stage:** 한서윤
**Staging:** none
- **Situation:** 벽 속 봉투 모서리와 120통이 함께 놓인다.
- **Beat:** 틈의 먼지와 장롱의 위치를 확인하고 얇은 면을 넣어 봉투를 천천히 꺼낸다.
- **Turn:** 봉투가 찢어지지 않은 채 벽 밖으로 나온다.
- **Function:** 021화의 봉투 모서리 Hook을 실행한다.
- **Sensory-emotional:** 오래된 먼지가 손목에 쌓인다 → 서윤은 숨을 멈추고 힘을 나눈다.
- **Dialogue intent:** none
- **Transition out:** 꺼낸 봉투를 장롱 앞에 놓고 120통과 비교한다.
- **Paragraph outline:** 1. 틈과 먼지를 확인 2. 얇은 면을 넣음 3. 힘을 나누어 당김 4. 봉투를 꺼냄 5. 장롱 앞으로 옮김
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 3×160 + transition 1×80 = 1,520
- **Est. length:** 1,500

### Scene 2 — 다른 날짜
**POV:** 한서윤 | **Location:** 어머니의-옛집 + 나무 장롱 앞 | **When:** 같은 날 오전
**On stage:** 한서윤
**Staging:** none
- **Situation:** 벽 속에서 나온 봉투와 120통이 장롱 앞에 나란히 놓인다.
- **Beat:** 두 봉투의 종이·봉인·번호·날짜·수신인 칸을 대조한다.
- **Turn:** 벽 속 봉투는 120통이 아니며, 더 오래된 다른 수신인 공백을 가진 편지임을 확인한다.
- **Function:** 마지막 통과 벽 속 봉투의 관계를 복잡하게 만든다.
- **Sensory-emotional:** 녹나무 냄새가 봉투에 밴 먼지 냄새와 섞인다 → 서윤은 봉투를 뒤집지 않고 겉면만 읽는다.
- **Dialogue intent:** none
- **Transition out:** 두 봉투를 마당의 빛으로 옮겨 색과 날짜를 다시 확인한다.
- **Paragraph outline:** 1. 두 봉투를 나란히 놓음 2. 종이와 봉인 비교 3. 날짜 차이 확인 4. 수신인 칸이 비어 있음을 확인 5. 120통이 아님을 인정 6. 마당으로 이동함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×120 + POV 4×160 + transition 1×80 = 1,800
- **Est. length:** 1,800

### Scene 3 — 두 개의 봉인
**POV:** 한서윤 | **Location:** 어머니의-옛집 + 마당의 수도가 | **When:** 같은 날 오후
**On stage:** 한서윤
**Staging:** none
- **Situation:** 마당의 약한 빛 아래 두 봉투가 흰 면 위에 놓인다.
- **Beat:** 서윤은 벽 속 봉투와 120통을 열지 않고 날짜·봉인·빈 수신인 칸을 함께 기록한다.
- **Turn:** 두 봉투가 같은 사람에게 향하지 않을 가능성을 남긴 채, 120통을 읽을 준비를 한다.
- **Function:** 023화의 120통 접근을 준비한다.
- **Sensory-emotional:** 수도가에서 물 한 방울이 떨어진다 → 서윤은 두 봉투 사이에 면을 끼운다.
- **Dialogue intent:** none
- **Transition out:** 두 개의 봉인된 봉투가 같은 흰 면 위에 놓인다.
- **Paragraph outline:** 1. 두 봉투를 빛 아래 옮김 2. 날짜와 봉인을 기록 3. 빈 수신인 칸을 나란히 봄 4. 두 봉투의 관계를 유보함 5. 흰 면 사이에 끼움
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

# Episode 015: 버려졌다고 믿은 날

## Summary
서윤은 해안 병원 기록실 앞에서 자신의 이름이 보호자 칸에 남아 있는지 확인한다. 기록의 존재만으로 과거를 해석하지 않은 채, 병원에 가져온 편지 중 자신이 버려졌다고 믿었던 날의 편지를 꺼내 읽는다. 편지는 그날을 ‘떠난 날’이라고 부르지 않고, 서윤은 문장과 기억 사이의 빈칸을 병원 복도와 현재의 몸으로 견딘다.

**Characters:** 한서윤, 윤서영 (편지 속 목소리)
**Locations:** 해안-병원, 서윤의-아파트

## Purpose
기록에 남은 서윤의 이름과 ‘버려졌다’는 기억을 같은 답으로 합치지 않고, 그날의 편지를 물리적 흔적과 함께 읽게 한다.

## Reader Engagement
### Personal Stake
보호자 기록에 자신의 이름이 있다면, 서윤이 지켜 온 버림의 기억은 기록과 충돌한다.
### Opening Question
이름이 기록에 남아 있어도, 그날 나는 정말 버려진 것일까?
### Stakes
기록을 믿으면 기억의 핵심이 흔들리고, 기억을 믿으면 편지와 병원의 증거를 외면하게 된다.

## Episode Arc
서윤은 병원 기록에서 보호자 이름의 존재를 확인하지만 그 의미를 확정하지 않는다. 복도에서 버려졌다고 믿었던 날의 편지를 꺼내 읽으며 어머니가 그날을 다른 이름으로 부른 흔적을 만난다. 집으로 돌아온 서윤은 편지 밑단에 남은 빗물과 연필심 가루를 발견하고, 기억을 판단하기보다 다음 증거를 보존한다.

## Scenes

### Scene 1 — 보호자 칸
**POV:** 한서윤 | **Location:** 해안-병원 + 기록실 앞 의자 | **When:** 2026년 늦가을, 014화 다음 날 오전
**On stage:** 한서윤
**Staging:** none

- **Situation:** 서윤이 병원 기록실 앞 의자에서 가져온 편지와 수첩을 꺼내 기록 확인을 기다린다.
- **Beat:** 기록지의 보호자 칸에 자신의 이름이 남아 있음을 확인하고, 이름 옆의 날짜와 문서 상태를 수첩에 옮긴다.
- **Turn:** 이름의 존재는 확인되지만, 그 이름이 어떤 역할을 뜻했는지는 기록만으로 알 수 없다는 한계가 남는다.
- **Function:** 014화의 병원 방문·보호자 기록 후크를 실행하고 기억과 기록의 충돌을 연다.
- **Sensory-emotional:** 투명 파일의 모서리가 무릎을 누른다 → 서윤은 이름을 만지지 않고 날짜만 옮긴다.
- **Dialogue intent:** none
- **Transition out:** 서윤은 기록지를 접지 않고 편지 봉투를 들고 바다를 향한 복도로 이동한다.
- **Paragraph outline:**
  1. 병원 복도와 기록실 앞 의자의 차가운 감각을 제시함
  2. 편지·수첩·기록지를 무릎 위에 정렬함
  3. 보호자 칸에서 자신의 이름을 발견함
  4. 이름 옆 날짜와 문서 상태를 옮겨 적음
  5. 기록의 의미를 확정하지 못한 채 편지를 들고 일어남
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

### Scene 2 — 떠난 날이 아닌 날
**POV:** 한서윤 | **Location:** 해안-병원 + 바다를 향한 복도 | **When:** 같은 날 오전, Scene 1 직후
**On stage:** 한서윤
**Staging:** none

- **Situation:** 서윤이 바다를 향한 복도 창가에서 자신이 버려졌다고 믿은 날의 편지를 꺼낸다.
- **Beat:** 편지의 날짜와 첫 문장을 읽고, 어머니가 그날을 ‘떠난 날’로 부르지 않은 표현을 날짜 아래에서 확인한다.
- **Turn:** 서윤의 기억을 반박하는 해명이 아니라, 기억과 다른 이름을 가진 하루가 남는다.
- **Function:** 버림의 감정을 즉시 뒤집지 않고 문장과 현재 장소 사이에 보류한다.
- **Sensory-emotional:** 유리 너머 바다가 보이지만 닿지 않는다 → 서윤은 편지를 접지 않은 채 손바닥의 땀을 닦는다.
- **Dialogue intent:** none
- **Transition out:** 편지의 밑단이 젖었다 마른 듯 울어 있는 것을 보고, 서윤은 원본을 가방에 넣는다.
- **Paragraph outline:**
  1. 바다를 향한 복도의 유리와 병원 냄새를 감지함
  2. 버려졌다고 믿은 날의 봉투를 꺼냄
  3. 날짜와 어머니의 다른 표현을 대조함
  4. 기억을 반박하거나 인정하지 못한 채 문장을 다시 읽음
  5. 편지 밑단의 변색과 눌림을 발견함
  6. 원본을 접어 가방에 넣고 병원을 떠날 준비를 함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×120 + POV 4×160 + transition 1×80 = 1,800
- **Est. length:** 1,800

### Scene 3 — 밑단의 흔적
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** 같은 날 밤
**On stage:** 한서윤
**Staging:** none

- **Situation:** 귀가한 서윤이 병원에서 가져온 편지를 창가의 낮은 탁자에 펼친다.
- **Beat:** 편지 밑단의 마른 빗물 자국과 연필심 가루를 확대경 없이 빛의 각도로 확인하고, 기록지의 이름과 함께 보존 봉투에 넣는다.
- **Turn:** 서윤은 그 흔적을 ‘그날의 증거’라고 결론 내리지 않고, 지워지기 전에 보관하기로 한다.
- **Function:** Episode Hook의 물리 단서를 구체화하고 다음 회차의 희생·거짓말 탐색으로 넘긴다.
- **Sensory-emotional:** 마른 물이 종이 섬유를 굳혀 놓았다 → 서윤은 가루를 털지 않고 종이 아래에 흰 면을 받친다.
- **Dialogue intent:** none
- **Transition out:** 보존 봉투 안에서 빗물 자국과 연필심 가루가 서로 닿은 채 남는다.
- **Paragraph outline:**
  1. 귀가 후 탁자 위에 기록지와 편지를 나란히 놓음
  2. 밑단의 빗물 얼룩을 빛의 각도로 확인함
  3. 연필심 가루가 섬유 사이에 박힌 것을 발견함
  4. 흔적의 원인을 단정하려다 멈춤
  5. 흰 면을 받치고 보존 봉투에 넣음
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

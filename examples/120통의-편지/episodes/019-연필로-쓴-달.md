## Purpose

## Reader Engagement
### Personal Stake
어머니가 되기 전의 윤서영을 만나면 서윤이 알고 있던 어머니의 시작점이 흔들린다.
### Opening Question
어머니가 아니었던 사람은 무엇을 기록했을까?
### Stakes
관계 이전의 목소리를 믿으면 현재의 어머니를 다시 써야 하고, 외면하면 120통의 문을 닫게 된다.

## Episode Arc
서윤은 119통의 오래된 종이와 연필 흔적을 확인한다. 편지는 딸을 부르지 않고 한 달의 날짜와 어떤 선택의 시작을 기록한다. 서윤은 윤서영이 어머니가 되기 전의 사람이라는 사실을 읽고, 120통의 봉투를 여는 순서를 편지 안에서 찾는다.

## Scenes

### Scene 1 — 가장 오래된 봉투
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** 018화 다음 날 오전
**On stage:** 한서윤
**Staging:** none
- **Situation:** 119통과 투명지가 탁자 위에 놓인다.
- **Beat:** 봉투 종이·연필 압력·번호를 이전 편지와 대조하고 119통을 개봉한다.
- **Turn:** 119통이 지금까지의 편지와 다른 시간에 속했음을 인정한다.
- **Function:** P3의 첫 문을 연다.
- **Sensory-emotional:** 봉투에서 마른 연필 냄새가 난다 → 서윤은 봉투를 천천히 연다.
- **Dialogue intent:** none
- **Transition out:** 편지 안쪽의 호칭 없는 첫 줄을 읽기 위해 바닥으로 옮긴다.
- **Paragraph outline:** 1. 119통을 꺼냄 2. 물성과 번호를 대조함 3. 봉투를 개봉함 4. 오래된 종이의 차이를 확인함 5. 첫 줄을 읽기 위해 이동함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 3×160 + transition 1×80 = 1,520
- **Est. length:** 1,500

### Scene 2 — 엄마가 아니던 사람
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 현관 쪽 바닥 | **When:** 같은 날 오후
**On stage:** 한서윤
**Staging:** none
- **Situation:** 119통의 편지가 차가운 바닥에 펼쳐진다.
- **Beat:** 딸을 부르는 호칭 없이 날짜·연필·한 선택을 기록한 편지 전문을 읽는다.
- **Turn:** 윤서영이 어머니가 되기 전의 사람이라는 사실이 현재의 관계와 분리되어 보인다.
- **Function:** 019화의 핵심 Summary를 실행한다.
- **Sensory-emotional:** 연필 자국이 종이 뒤까지 눌려 있다 → 서윤은 손바닥을 편지 위에 대지 않는다.
- **Dialogue intent:** none
- **Transition out:** 마지막 문장에서 120통을 여는 순서가 언급된다.
- **Paragraph outline:** 1. 편지의 호칭 부재를 확인함 2. 날짜와 연필 압력을 읽음 3. 선택의 문장을 만남 4. 어머니 이전의 시간을 감지함 5. 현재의 기억과 분리함 6. 마지막 순서 문장을 읽음
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×120 + POV 4×160 + transition 1×80 = 1,800
- **Est. length:** 1,800

### Scene 3 — 다음 봉투를 여는 법
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 벽 쪽 수납장 | **When:** 같은 날 밤
**On stage:** 한서윤
**Staging:** none
- **Situation:** 119통 편지와 120통 봉투가 수납장 앞에 놓인다.
- **Beat:** 마지막 문장이 알려 준 순서대로 120통의 봉인 아래를 확인하고 얇은 연필 조각을 발견한다.
- **Turn:** 120통은 열 수 있지만, 지금 바로 전문을 읽지는 않기로 한다.
- **Function:** 020화의 마지막 전 편지와 120통으로 연결한다.
- **Sensory-emotional:** 봉인 아래 연필 조각이 손톱에 걸린다 → 서윤은 봉투를 다시 눕힌다.
- **Dialogue intent:** none
- **Transition out:** 120통 봉투의 봉인 아래에 얇은 연필 조각이 끼워진다.
- **Paragraph outline:** 1. 두 봉투를 나란히 놓음 2. 119통의 순서를 재확인함 3. 120통 봉인을 살핌 4. 연필 조각을 발견함 5. 봉투를 열지 않고 눕힘
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

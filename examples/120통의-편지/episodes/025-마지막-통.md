## Scenes

### Scene 1 — 남은 문장
**POV:** 한서윤 | **Location:** 어머니의-옛집 + 안쪽 벽의 틈 | **When:** 024화 다음 날 오전
**On stage:** 한서윤
**Staging:** none

- **Situation:** 질문 아래 낙서를 덮은 투명 면이 있고, 120통의 남은 문장이 펼쳐질 준비를 한다.
- **Beat:** 서윤은 질문 다음의 문장들을 이어 읽으며, 어머니가 자신의 답을 대신 쓰지 않고 질문·침묵·빈자리를 반복해 남겼음을 확인한다.
- **Turn:** 120통의 전문이 특정 사건의 보고서가 아니라 답장할 사람을 향한 첫 번째 대화였음을 감지한다.
- **Function:** 024화의 질문과 답장 공간을 전문의 전체 방향으로 연결한다.
- **Sensory-emotional:** 투명 면 아래 낙서의 선이 빛에 따라 흐려진다 → 서윤은 종이를 움직이지 않고 문장만 넘긴다.
- **Dialogue intent:** none — 윤서영의 목소리는 편지 텍스트 안에만 존재한다.
- **Transition out:** 전문의 중간에서 헤어진 직후의 날짜와 첫 질문의 사유가 나타나고, 서윤은 마당으로 편지를 옮긴다.
- **Paragraph outline:**
  1. 보호된 낙서와 펼쳐진 120통의 위치를 확인한다.
  2. 질문 다음 문장을 이어 읽으며 빈자리의 반복을 찾는다.
  3. 어머니가 답을 대신 쓰지 않은 문장 구조를 관찰한다.
  4. 편지가 보고서가 아니라 첫 대화였음을 감지한다.
  5. 투명 면 아래 낙서와 편지의 글씨를 겹쳐 본다.
  6. 출발점의 날짜가 나타난 전문을 마당으로 옮긴다.
- **Unit budget:** dialogue 0 + action 3×180 + sensory 3×120 + POV 3×160 + transition 1×80 = 1,460
- **Est. length:** 1,500

### Scene 2 — 시작한 사람
**POV:** 한서윤 | **Location:** 어머니의-옛집 + 마당의 수도가 | **When:** 같은 날 오전, Scene 1 직후
**On stage:** 한서윤
**Staging:** none

- **Situation:** 120통의 전문이 마당의 흰 면 위에서 계속 펼쳐지고, 벽 속 봉투는 닫힌 채 집 안에 남아 있다.
- **Beat:** 서윤은 윤서영이 헤어진 직후 첫 질문을 쓴 이유, 답을 받지 못해도 다음 달 편지를 이어 쓴 선택, 부치지 않은 봉투를 자신에게 돌려보낸 시작을 읽는다.
- **Turn:** 어머니의 출발점이 딸을 설득하려는 계획이 아니라, 말이 끊긴 뒤에도 질문을 보존하려는 행동이었음을 이해한다.
- **Function:** Episode Summary의 ‘어머니의 출발점’을 전문 속 사건으로 실행한다.
- **Sensory-emotional:** 수도가의 물이 흰 면 가장자리를 피해 흐른다 → 서윤은 문장을 접지 않고 젖지 않는 곳으로 면만 조금 옮긴다.
- **Dialogue intent:** none — 어머니의 발화는 편지 전문 안에서만 직접 제시된다.
- **Transition out:** 마지막 접힌 면에 001화에서 이미 읽은 문장과 같은 시간 방향이 나타난다.
- **Paragraph outline:**
  1. 마당의 빛 아래 전문의 중간 날짜를 확인한다.
  2. 헤어진 직후 첫 질문이 쓰인 상황을 편지 속 문장으로 읽는다.
  3. 답이 오지 않아도 다음 달 편지를 이어 간 선택을 따라간다.
  4. 부치지 않은 봉투가 돌아오는 시작을 물성으로 확인한다.
  5. 설득이 아닌 질문 보존이라는 출발점을 서윤의 현재와 대조한다.
  6. 마지막 접힌 면의 첫 문장 공명 단서를 발견한다.
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×120 + POV 4×160 + transition 1×80 = 1,800
- **Est. length:** 1,800

### Scene 3 — 처음의 문장
**POV:** 한서윤 | **Location:** 어머니의-옛집 + 나무 장롱 앞 | **When:** 같은 날 오후
**On stage:** 한서윤
**Staging:** none

- **Situation:** 120통의 마지막 면이 장롱 앞에 놓이고, 벽 속 봉투는 옆에서 여전히 봉인되어 있다.
- **Beat:** 서윤은 마지막 줄을 읽고, 그 시간 방향과 001화에서 처음 읽었던 「이 편지가 네 손에 닿을 때쯤이면」을 겹쳐 확인한다.
- **Turn:** 마지막 줄이 첫 통의 첫 문장으로 돌아가는 공명을 만들자, 서윤은 120통을 완독했음을 인정하고 답장을 쓸 종이를 꺼낸다.
- **Function:** 제120통의 전문을 닫고 026화의 답장으로 문턱을 넘긴다.
- **Sensory-emotional:** 장롱의 마른 나무 위에서 봉투가 닫히는 소리가 난다 → 서윤은 연필을 봉투 위에 올려두고 손을 떼지 못한다.
- **Dialogue intent:** none — 마지막 줄과 001화 문장은 모두 편지 텍스트의 공명으로 처리한다.
- **Transition out:** 닫힌 120통 위에 연필이 놓이고 서윤의 손이 봉투에서 떨어지지 않는다.
- **Paragraph outline:**
  1. 마지막 면과 닫힌 벽 속 봉투의 위치를 함께 잡는다.
  2. 120통의 마지막 줄을 읽고 날짜와 문장 방향을 확인한다.
  3. 001화에서 읽은 첫 문장과 마지막 줄의 공명을 인식한다.
  4. 완독의 의미를 용서와 분리해 현재의 손으로 받아들인다.
  5. 답장을 위한 종이와 연필을 꺼내지만 첫 글자는 쓰지 않는다.
  6. 닫힌 120통 위에 연필을 놓은 채 손을 떼지 못한다.
- **Unit budget:** dialogue 0 + action 3×180 + sensory 3×120 + POV 4×160 + transition 1×80 = 1,620
- **Est. length:** 1,600

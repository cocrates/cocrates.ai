# Episode 017: 거짓말의 수신인

## Summary
서윤은 ‘딸을 살리기 위해 거짓말했다’는 문장을 다시 읽으며, 그 거짓말이 자신에게가 아니라 다른 사람에게 향했을 가능성을 추적한다. 편지의 문장 끝과 수신인 칸의 눌림을 대조하는 과정에서, 모든 편지에서 지워진 이름이 단순한 삭제가 아니라 보호를 위한 흔적일 수 있음을 발견한다. 이름은 확정하지 않고, 지워진 자국만 다음 회차의 증거로 남긴다.

**Characters:** 한서윤, 윤서영 (편지 속 목소리)
**Locations:** 서윤의-아파트

## Purpose
거짓말의 방향을 서윤에게서 떼어 내고, 지워진 이름을 보호의 흔적으로 읽을 가능성을 만든다.

## Reader Engagement
### Personal Stake
거짓말이 자신을 향한 것이 아니라면 서윤의 원망은 다른 사람의 이름 위에 세워졌을 수 있다.
### Opening Question
어머니는 나에게 거짓말한 것일까, 나를 위해 다른 사람에게 거짓말한 것일까?
### Stakes
수신인을 찾으면 원망의 방향이 바뀌지만, 이름을 복원하면 누군가의 보호를 깨뜨릴 수 있다.

## Episode Arc
서윤은 016화의 문장을 세 편지의 끝맺음과 비교한다. 수신인 칸의 눌림과 지워진 흔적은 반복되지만 이름을 복원할 만큼 선명하지 않다. 서윤은 이름을 추정하지 않고 지워짐 자체를 기록하며, 다음 회차에서 흔적을 확대하기로 한다.

## Scenes

### Scene 1 — 다른 사람에게
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** 016화 다음 날 오전
**On stage:** 한서윤
**Staging:** none
- **Situation:** 서윤이 희생 문장과 빈 수신인 봉투를 다시 펼친다.
- **Beat:** ‘나를 살리기 위해’와 ‘나에게 거짓말했다’를 수첩에 나란히 적고 문장의 차이를 비교한다.
- **Turn:** 거짓말이 자신에게 직접 향하지 않았을 가능성을 인정한다.
- **Function:** 원망의 방향을 다른 수신인으로 이동한다.
- **Sensory-emotional:** 지우개 가루가 수첩의 접힌 곳에 모인다 → 서윤은 가루를 털지 않는다.
- **Dialogue intent:** none
- **Transition out:** 비교할 편지 세 통을 현관 쪽 바닥에 펼친다.
- **Paragraph outline:** 1. 봉투와 문장을 꺼냄 2. 두 표현을 나란히 씀 3. 문장 차이를 읽음 4. 원망의 방향을 의심함 5. 세 편지를 고름
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 3×160 + transition 1×80 = 1,520
- **Est. length:** 1,500

### Scene 2 — 지운 자리의 반복
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 현관 쪽 바닥 | **When:** 같은 날 오후
**On stage:** 한서윤
**Staging:** none
- **Situation:** 서로 다른 계절의 편지 세 통이 바닥에 펼쳐진다.
- **Beat:** 문장 끝·수신인 칸·접힌 선을 비교하다가 세 편지에 같은 위치의 지워진 흰 자국이 있음을 확인한다.
- **Turn:** 이름이 한 번 지워진 것이 아니라 반복해서 숨겨졌을 가능성이 열린다.
- **Function:** Series Hook의 ‘모든 편지에서 지워진 이름’을 물리적으로 시작한다.
- **Sensory-emotional:** 바닥의 냉기가 종이 가장자리로 올라온다 → 서윤은 편지를 손으로 누르지 않고 책으로 고정한다.
- **Dialogue intent:** none
- **Transition out:** 지워진 자국을 확대할 도구를 찾으러 수납장으로 이동한다.
- **Paragraph outline:** 1. 세 편지의 날짜를 맞춤 2. 수신인 칸을 비교함 3. 같은 위치의 흰 자국을 찾음 4. 종이 결과 지우개 가루를 확인함 5. 이름을 복원하려다 멈춤 6. 확대 도구를 찾기로 함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×120 + POV 4×160 + transition 1×80 = 1,800
- **Est. length:** 1,800

### Scene 3 — 복원하지 않기
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 벽 쪽 수납장 | **When:** 같은 날 밤
**On stage:** 한서윤
**Staging:** none
- **Situation:** 서윤이 수납장 앞에서 편지와 확대 도구를 놓고 지워진 자국을 바라본다.
- **Beat:** 첫 글자를 추정해 적으려다 멈추고, 자국의 위치·크기·종이 상태만 기록한다.
- **Turn:** 이름을 복원하지 않고 지워짐 자체를 다음 증거로 보존한다.
- **Function:** 후반 이름 공개를 보호하며 018화의 확대·확인으로 연결한다.
- **Sensory-emotional:** 흰 자국이 조명 아래에서 거의 보이지 않는다 → 서윤은 불을 끄고도 봉투를 치우지 않는다.
- **Dialogue intent:** none
- **Transition out:** 세 편지의 같은 위치에 남은 흰 자국이 한 면에 정렬된다.
- **Paragraph outline:** 1. 확대 도구를 꺼냄 2. 첫 글자를 추정함 3. 추정을 지움 4. 자국의 물리 정보만 기록함 5. 세 편지를 정렬해 보존함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

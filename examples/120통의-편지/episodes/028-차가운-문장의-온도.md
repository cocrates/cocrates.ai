# Episode 028: 차가운 문장의 온도

## Summary
서윤은 제1통을 다시 꺼내 봉투를 열고, 처음 읽을 때 자신을 버린 증거처럼 붙잡았던 문장들을 현재의 자리에서 재독한다. 문장의 사실이 바뀐 것은 아니지만, 날짜·종이·문장 사이의 짧은 멈춤을 따라가며 서윤은 그 말의 온도가 자신이 기억한 것보다 덜 단정적이었음을 감지한다. 서윤은 어머니를 용서하거나 답장을 완성하지 않은 채, 처음으로 답장의 수취인 칸에 어머니의 이름을 쓴다.

## Purpose
제1통의 사실을 바꾸지 않고 그 문장을 읽는 서윤의 위치를 바꾸어, 답장의 수취인 칸에 어머니의 이름을 쓰게 한다.

## Reader Engagement (Episode Level)
### Personal Stake
어머니의 이름을 수취인으로 쓰는 순간 서윤은 답장을 누구에게 하는지 처음으로 인정한다. 그러나 이름을 쓴다고 해서 원망이 사라지거나 편지가 보내지는 것은 아니므로, 응답의 방향만 먼저 확정한다.

### Opening Question
같은 문장이 사실을 바꾸지 않은 채 다른 온도로 읽힐 수 있을까?

### Reader Questions
- 서윤이 차갑게 읽었던 문장의 어디에서 망설임을 발견하는가?
- 이름을 쓴 답장은 실제로 누구에게, 어떤 방식으로 닿게 될 것인가?

### Stakes
재독이 단순한 자기위안이면 서윤은 첫 읽기의 판결로 돌아간다. 문장의 온도를 다시 감지하면 어머니를 이해하는 책임과 자신이 남길 답장의 책임을 동시에 떠안게 된다.

## Episode Arc
서윤은 제1통을 열어 처음의 표시와 문장 배열을 다시 확인한다. 첫 읽기 때 자신을 버렸다는 증거로만 읽었던 단정적인 말 사이에서 날짜의 멈춤과 사물에서 감정으로 들어가는 문장 구조를 발견하지만, 그것을 어머니의 변명이나 진실로 확정하지 않는다. 재독이 끝난 뒤 서윤은 답장 종이를 펼쳐 빈 수취인 칸에 윤서영의 이름을 쓰고, 아직 보내지 않은 답장의 방향만 정한다.

## Scenes

### Scene 1 — 봉투를 여는 손
**POV:** 한서윤 | **Location:** 어머니의-옛집 + 나무 장롱 앞 | **When:** 027화 다음 날 오전, 제1통을 다시 꺼내 놓은 다음 날
**On stage:** 한서윤
**Staging:** none

- **Situation:** 제1통은 답장 종이 옆에 놓여 있고, 서윤은 봉투를 열기 전 자신의 표시와 날짜를 다시 확인한다.
- **Beat:** 서윤은 봉투의 접힌 모서리를 만지고 봉인 흔적을 살핀 뒤 제1통을 연다. 처음 읽을 때 손톱으로 남긴 표시와 문장이 놓인 간격을 대조하며, 기억 속 단정과 실제 종이의 배열 사이에 차이가 있음을 확인한다.
- **Turn:** 제1통은 같은 내용으로 남아 있지만, 서윤은 이번에는 뜻을 먼저 판정하지 않고 문장이 놓인 순서부터 읽기로 한다.
- **Function:** Prior Hook인 재독을 실제 개봉 행동으로 실행하고 Scene 2의 온도 변화를 위한 관찰 기반을 놓는다.
- **Sensory-emotional:** 마른 봉투가 열릴 때 접힌 섬유가 작게 갈라진다 → 서윤은 종이를 급히 펴지 않고 손바닥으로 눌러 평평하게 한다.
- **Dialogue intent:** none
- **Transition out:** 서윤은 제1통의 문장을 한 번에 끝까지 읽지 않고, 문장 사이의 흰 틈마다 손가락을 멈춘다.
- **Paragraph outline:**
  1. 답장 종이 옆 제1통과 아침의 장롱 표면을 제시한다.
  2. 봉투 접힘·날짜·처음의 표시를 손으로 확인한다.
  3. 봉투를 열고 종이를 급히 펴지 않는다.
  4. 처음 읽을 때의 기억과 실제 문장 간격을 대조한다.
  5. 뜻을 판정하기보다 배열을 먼저 읽는 태도로 전환한다.
  6. 문장 사이의 흰 틈에서 손가락을 멈추며 다음 장면으로 넘긴다.
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×120 + POV 3×160 + transition 1×80 = 1,700
- **Est. length:** 1,700

### Scene 2 — 덜 차가운 문장
**POV:** 한서윤 | **Location:** 어머니의-옛집 + 안쪽 벽의 틈 | **When:** 같은 날 오전, Scene 1 직후
**On stage:** 한서윤
**Staging:** none

- **Situation:** 벽 틈의 약한 빛 아래 제1통의 펼쳐진 종이와 첫 답장 종이가 나란히 놓인다.
- **Beat:** 서윤은 처음 읽을 때 자신을 버린 증거로 붙잡았던 문장을 다시 읽고, 그 문장 앞뒤의 날짜 표기와 사물에서 감정으로 이동하는 짧은 흐름을 확인한다. 사실이나 문장 자체는 바뀌지 않았지만, 단정으로만 들리던 말이 상대의 결론을 닫지 않은 채 멈춰 있었음을 감지한다.
- **Turn:** 서윤은 ‘따뜻한 진심’이라고 이름 붙이지 않고, 문장의 차가움이 자신의 읽기에서 더해졌을 가능성을 인정한다.
- **Function:** Episode Title의 문장 온도 변화를 해설 없이 재독의 순서와 종이의 간격으로 실행한다.
- **Sensory-emotional:** 벽 틈의 빛이 잉크의 진한 부분보다 번진 가장자리를 먼저 드러낸다 → 서윤은 지우지 않고 번진 곳에 종이 모서리를 맞춘다.
- **Dialogue intent:** none — 윤서영의 목소리는 제1통 안의 기록으로만 존재한다.
- **Transition out:** 서윤은 제1통을 접지 않고 옆에 둔 채, 첫 답장 종이의 빈 수취인 칸을 자신 쪽으로 당긴다.
- **Paragraph outline:**
  1. 벽 틈의 빛 아래 두 종이를 나란히 놓는다.
  2. 처음 원망으로 붙잡았던 문장을 다시 확인한다.
  3. 날짜와 사물 묘사가 문장 앞뒤에서 만드는 멈춤을 읽는다.
  4. 사실은 같지만 단정의 온도가 달라지는 감각을 포착한다.
  5. 이를 용서나 진심의 증명으로 이름 붙이지 않는다.
  6. 제1통을 옆에 두고 답장 수취인 칸을 당긴다.
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×120 + POV 4×160 + transition 1×80 = 1,800
- **Est. length:** 1,800

### Scene 3 — 수취인 칸
**POV:** 한서윤 | **Location:** 어머니의-옛집 + 마당의 수도가 | **When:** 같은 날 오후, 빛이 기울기 시작할 무렵
**On stage:** 한서윤
**Staging:** none

- **Situation:** 제1통은 펼쳐진 채 옆에 있고, 답장 종이의 수취인 칸과 비어 있는 본문이 수도가 옆의 흰 면 위에 놓인다.
- **Beat:** 서윤은 수취인 칸을 여러 번 바라보다 윤서영의 이름을 적는다. 이름 아래 본문을 바로 채우지 않고 연필을 내려놓으며, 이름을 쓴 행위와 편지를 보낼 결정은 서로 다른 일로 남겨 둔다.
- **Turn:** 답장은 더 이상 이름 없는 기록이 아니라 어머니에게 향할 수 있는 문서가 되지만, 아직 발송될 편지는 아니다.
- **Function:** Episode List Hook to Next인 ‘수취인 칸에 어머니의 이름’을 관찰 가능한 행동으로 실행하고 029화의 답장 완성 선택을 준비한다.
- **Sensory-emotional:** 수도가의 물이 흰 면 가장자리에서 끊겨 작은 어둠을 만든다 → 서윤은 이름 아래 빈 본문을 젖지 않게 안쪽으로 당긴다.
- **Dialogue intent:** none
- **Transition out:** 윤서영의 이름 아래 빈 본문과 펼쳐진 제1통이 기우는 오후 빛 안에 남는다.
- **Paragraph outline:**
  1. 제1통과 답장 종이의 수취인 칸을 수도가 옆에 놓는다.
  2. 빈 칸을 바라보며 이름과 발송의 차이를 확인한다.
  3. 연필로 윤서영의 이름을 한 번에 쓰지 못하고 획을 고른다.
  4. 이름이 실제 종이에 남는 순간을 보여 준다.
  5. 본문을 쓰려다 멈추고 발송 결정을 분리해 둔다.
  6. 이름 아래 빈 본문과 펼쳐진 제1통을 closing image로 남긴다.
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×120 + POV 3×160 + transition 1×80 = 1,700
- **Est. length:** 1,700

## Reader Engagement (Episode Level)
### Personal Stake
병원에 가면 자신이 몰랐던 보호자 역할과 마주칠 수 있다.
### Opening Question
어머니는 왜 병원 이름을 편지에 남겼지만, 자신이 다녀온 사실은 말하지 않았을까?

## Episode Arc
서윤은 병원 이름을 다시 읽고 주소와 운영 기록을 찾는다. 오래된 수첩의 날짜와 편지의 표현을 대조하며 병원이 2017년 가을 공백 근처에 있었다는 사실을 확인한다. 마지막에는 무날짜 봉투와 병원명 수첩을 함께 가방에 넣고, 아직 열지 않은 봉투를 들고 이동할 준비를 한다.

## Scenes

### Scene 1 — 이름을 검색하는 밤
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** 2026년 늦가을, Episode 012 다음 날 밤
**On stage:** 한서윤
**Staging:** none
- **Situation:** 서윤은 병원명 수첩과 편지를 옆에 두고 현재의 병원 정보를 찾는다.
- **Beat:** 이름의 옛 표기와 현재 주소를 검색하고, 편지의 날짜와 병원 운영 기록을 대조한다.
- **Turn:** 병원이 실제 장소이며 2017년 가을 공백과 시간상 겹칠 수 있음을 확인한다.
- **Function:** 장소명을 방문 가능한 현실로 바꾼다.
- **Sensory-emotional:** 화면의 흰 검색창이 수첩의 누런 종이와 대비된다 → 서윤은 검색 결과보다 병원명을 쓴 어머니의 잉크를 먼저 본다.
- **Dialogue intent:** none
- **Transition out:** 오래된 기록을 더 찾기 위해 수첩의 뒷장을 펼친다.
- **Paragraph outline:**
  1. 병원명 수첩과 편지를 탁자에 놓음
  2. 옛 표기와 현재 주소를 검색함
  3. 날짜와 운영 시기를 대조함
  4. 실제 장소라는 확인 앞에서 화면을 닫지 못함
  5. 수첩의 뒷장을 찾아 오래된 기록을 확인하려 함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 3×160 + transition 1×80 = 1,520
- **Est. length:** 1,500

### Scene 2 — 오래된 접수창
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 벽 쪽 수납장 | **When:** 같은 밤, Scene 1 직후
**On stage:** 한서윤
**Staging:** none
- **Situation:** 서윤은 공개된 병원 기록과 편지의 표현에서 접수 기록의 빈칸을 추정한다.
- **Beat:** 오래된 병원 안내 페이지와 보존 기록 안내를 읽고, 접수 창구에서 확인할 수 있는 항목을 수첩에 적는다. 환자·보호자라는 두 칸을 적은 뒤 자신의 이름을 쓰지 못한다.
- **Turn:** 보호자 기록에 자신의 이름이 있을 가능성을 처음으로 구체적으로 상상한다.
- **Function:** 다음 회차의 접수 기록 Hook을 준비한다.
- **Sensory-emotional:** 수납장 유리에 병원명 수첩이 거꾸로 비친다 → 서윤은 이름 칸을 비운 채 펜을 내려놓는다.
- **Dialogue intent:** none
- **Transition out:** 병원에 가져갈 편지와 무날짜 봉투를 고르기 시작한다.
- **Paragraph outline:**
  1. 병원 기록 안내를 읽고 접수 항목을 분류함
  2. 환자와 보호자 두 칸을 수첩에 그림
  3. 보호자 칸 앞에서 자신의 이름을 쓰려다 멈춤
  4. 가능성을 사실처럼 만들지 않기 위해 칸을 비움
  5. 확인을 위해 가져갈 물건을 고르는 행동으로 이동
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

### Scene 3 — 가져갈 것들
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** 자정 무렵
**On stage:** 한서윤
**Staging:** none
- **Situation:** 병원명 수첩, 해당 편지, 무날짜 봉투가 탁자 위에 놓인다.
- **Beat:** 서윤은 편지와 수첩을 가방에 넣고 무날짜 봉투는 넣을지 망설인다. 결국 봉투를 열지 않은 채 별도 천에 싸서 함께 넣는다.
- **Turn:** 병원 기록에 자신을 대입할 가능성을 피하지 않고 이동을 준비한다.
- **Function:** 장소 조사에서 실제 방문으로 넘어가는 몸의 결심을 만든다.
- **Sensory-emotional:** 가방 안에서 봉투가 서로 닿지 않도록 천이 마찰한다 → 서윤은 지퍼를 끝까지 닫는다.
- **Dialogue intent:** none
- **Transition out:** 닫힌 가방이 현관에 놓이고, 병원명 수첩과 무날짜 봉투가 같은 이동을 기다린다.
- **Paragraph outline:**
  1. 세 물건을 탁자 위에 배열함
  2. 해당 편지와 수첩을 가방에 넣음
  3. 무날짜 봉투를 넣을지 망설임
  4. 열지 않은 채 천으로 감싸 넣음
  5. 지퍼를 닫고 가방을 현관에 둠
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

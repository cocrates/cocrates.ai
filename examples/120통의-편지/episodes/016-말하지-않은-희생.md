# Episode 016: 말하지 않은 희생

## Summary
서윤은 015화에서 보존한 보호자 기록과 빗물·연필심 흔적을 다시 대조하며, 어머니가 숨긴 선택의 범위를 추적한다. 2017년 9월 편지의 빈 줄과 다른 필체는 손 부상만이 아니라 누군가가 말하지 않기로 한 대가를 가리킨다. 편지 안에서 어머니는 서윤을 살리기 위해 거짓말을 했다고 적지만, 그 거짓말의 수신인과 희생의 내용은 밝히지 않는다.

**Characters:** 한서윤, 윤서영 (편지 속 목소리)

## Purpose
희생을 해설하지 않고 편지의 빈칸과 한 문장으로 드러내며, 어머니의 거짓말이 서윤을 향한 직접 해명이 아님을 남긴다.

## Reader Engagement
### Personal Stake
어머니의 거짓말이 서윤을 살리기 위한 것이었다면, 서윤이 믿어 온 버림의 기억은 다른 사람을 향한 거짓말과 충돌한다.
### Opening Question
살리기 위한 거짓말은 누구에게 필요한 것이었을까?
### Stakes
문장을 믿으면 희생의 대가를 추적해야 하고, 믿지 않으면 편지의 빈칸을 다시 닫게 된다.

## Episode Arc
서윤은 기록·편지·보존 봉투의 흔적을 재배열한다. 빈 줄 뒤에 남은 눌림과 다른 필체의 문장 끝을 대조하다가, 어머니가 누군가에게 거짓말을 했다는 문장을 읽는다. 문장은 서윤을 살리기 위한 것이었다고 하지만 수신인을 밝히지 않고, 서윤은 수신인 칸을 비워 둔 채 편지를 다시 봉인한다.

## Scenes

### Scene 1 — 세 가지 증거
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** 015화 다음 날 오전
**On stage:** 한서윤
**Staging:** none
- **Situation:** 서윤이 보호자 기록지와 9월 편지, 보존 봉투를 탁자에 펼친다.
- **Beat:** 세 물건의 날짜·접힘·물성 흔적을 비교하되 서로 닿지 않게 배열한다.
- **Turn:** 흔적들이 같은 사건을 증명하지 않는다는 사실을 받아들인다.
- **Function:** 015화의 단서를 희생 추적으로 확장한다.
- **Sensory-emotional:** 보존 봉투의 비닐이 종이보다 차갑다 → 서윤은 손을 번갈아 닦는다.
- **Dialogue intent:** none
- **Transition out:** 빈 줄이 눌린 위치를 확인하기 위해 편지를 현관 쪽 바닥으로 옮긴다.
- **Paragraph outline:** 1. 세 물건을 꺼냄 2. 날짜와 접힘을 비교함 3. 닿지 않게 배열함 4. 하나의 증거로 묶으려다 멈춤 5. 빈 줄의 눌림을 다시 확인함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 3×160 + transition 1×80 = 1,520
- **Est. length:** 1,500

### Scene 2 — 빈 줄 뒤의 문장
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 현관 쪽 바닥 | **When:** 같은 날 오후
**On stage:** 한서윤
**Staging:** none
- **Situation:** 편지와 확대하지 않은 원본이 차가운 바닥에 놓인다.
- **Beat:** 눌린 빈 줄과 다른 필체의 문장 끝을 빛의 각도로 대조하다가, 접힌 면 안쪽의 짧은 문장을 읽는다.
- **Turn:** 어머니가 딸을 살리기 위해 거짓말했다고 적은 문장을 확인한다.
- **Function:** Series Hook의 핵심 문장을 공개하되 희생의 내용은 보류한다.
- **Sensory-emotional:** 종이의 접힌 선이 손가락 끝을 긁는다 → 서윤은 문장을 다시 덮는다.
- **Dialogue intent:** none
- **Transition out:** 문장을 옮겨 적지 않고 봉투의 수신인 칸을 확인한다.
- **Paragraph outline:** 1. 바닥의 냉기와 종이 결을 감지함 2. 빈 줄의 눌림을 비춤 3. 다른 필체의 끝맺음을 비교함 4. 숨은 문장을 읽음 5. ‘살리기 위해 거짓말’이라는 문장을 되읽음 6. 수신인 칸을 보기 위해 일어남
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×120 + POV 4×160 + transition 1×80 = 1,800
- **Est. length:** 1,800

### Scene 3 — 수신인 칸
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 벽 쪽 수납장 | **When:** 같은 날 밤
**On stage:** 한서윤
**Staging:** none
- **Situation:** 편지 봉투와 보존 봉투가 수납장 앞에 놓인다.
- **Beat:** 서윤은 수신인 칸에 자신의 이름을 쓰려다 지우고, 빈 칸을 보존한 채 편지를 봉인한다.
- **Turn:** 거짓말의 수신인을 추정하지 않고 다음 기록으로 넘기기로 한다.
- **Function:** 희생의 공개를 멈추고 017화의 수신인 탐색을 건다.
- **Sensory-emotional:** 봉인용 풀이 굳으며 얇은 막을 만든다 → 서윤은 손가락을 떼고 칸을 비워 둔다.
- **Dialogue intent:** none
- **Transition out:** 수신인 칸이 빈 봉투가 보존 봉투 안에 들어간다.
- **Paragraph outline:** 1. 수신인 칸을 확인함 2. 자신의 이름을 시험 삼아 씀 3. 곧바로 지움 4. 빈칸의 흔적을 보존함 5. 봉투를 보존 봉투에 넣음
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

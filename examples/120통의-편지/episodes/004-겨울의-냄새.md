## Scenes
### Scene 1 — 겨울이 묻은 봉투
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 현관 쪽 바닥 | **When:** 2026년 늦가을, 우체국에서 돌아온 저녁
**On stage:** 한서윤
**Staging:** none
- **Situation:** 가방 속 제4통이 현관 바닥에 놓인다.
- **Beat:** 서윤은 봉투를 꺼내 냄새와 종이의 두께를 확인하고, 우체국의 젖은 외투 냄새와 다른 오래된 겨울 냄새를 맡는다.
- **Turn:** 봉투 안쪽에서 작은 달력 조각이 떨어진다.
- **Function:** 제4통의 개봉을 물성의 사건으로 만든다.
- **Sensory-emotional:** 차가운 바닥과 마른 종이 냄새 → 서윤은 외투도 벗지 않고 봉투를 든다.
- **Dialogue intent:** none
- **Transition out:** 달력 조각의 날짜를 확인한 뒤 창가의 탁자로 이동한다.
- **Paragraph outline:** 1. 귀가와 가방 내려놓기 2. 제4통의 차가운 표면 3. 겨울 냄새 관찰 4. 달력 조각 발견 5. 날짜 확인 6. 탁자로 이동
- **Unit budget:** dialogue 0 + action 4×180 + sensory 4×130 + POV 3×150 + transition 1×80 = 1,910
- **Est. length:** 1,900

### Scene 2 — 약속의 날짜
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** Scene 1 직후, 같은 저녁
**On stage:** 한서윤
**Staging:** none
- **Situation:** 제4통과 달력 조각이 탁자 위에 놓인다.
- **Beat:** 편지는 2026년 8월 17일자로, 떠난 뒤에도 매달 한 통을 쓰겠다는 약속과 겨울의 냄새를 기록한다.
- **Turn:** 서윤은 달력에 편지 날짜를 옮기며 자신이 사라졌다고 믿은 계절에도 어머니의 날짜가 이어졌음을 확인한다.
- **Function:** P1의 ‘지속’ 정서를 구체화한다.
- **Sensory-emotional:** 잉크가 종이 섬유에 깊이 밴 감촉 → 서윤은 손가락을 떼지 못한다.
- **Dialogue intent:** 윤서영의 편지는 답을 요구하지 않고 매달 쓰는 약속을 기록하는 낮은 목소리.
- **Transition out:** 서윤이 제5통을 꺼내자 봉투에서 더 오래된 종이 냄새가 난다.
- **Paragraph outline:** 1. 날짜 헤더와 달력 조각 2. 겨울을 기록한 편지 전문 도입 3. 매달 쓰겠다는 약속 4. 떠난 뒤의 계절 기록 5. 서윤의 달력 대조 6. 제5통의 냄새로 이동
- **Unit budget:** dialogue 4×260 + action 4×180 + sensory 4×130 + POV 4×150 + transition 1×80 = 3,240
- **Est. length:** 3,200

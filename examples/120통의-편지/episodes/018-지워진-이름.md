# Episode 018: 지워진 이름

## Summary
서윤은 세 편지에 반복된 지워진 흔적을 확대·대조한다. 종이의 눌림과 연필심 방향을 겹쳐 보며 이름의 첫 글자가 어머니의 이름과 같은 방향으로 시작했을 가능성을 발견하지만, 글자 전체를 복원하지 않는다. 지워진 이름이 보호를 위한 행위였을 수 있다는 감각만 남기고, 서윤은 오래된 편지 영역으로 들어간다.

**Characters:** 한서윤, 윤서영 (편지 속 목소리)

## Purpose
지워진 이름을 완전히 복원하지 않고도, 그 이름이 왜 숨겨졌는지 추적할 수 있는 첫 방향을 만든다.

## Reader Engagement
### Personal Stake
첫 글자가 어머니의 이름과 닮았다면, 서윤은 수신인을 타인으로만 생각할 수 없게 된다.
### Opening Question
지워진 이름은 누구를 숨기기 위해 지워졌을까?
### Stakes
첫 글자를 확정하면 후반의 지워진 이름이 조기 노출되고, 보류하면 단서를 잃을 수 있다.

## Episode Arc
서윤은 확대 도구와 빛을 이용해 세 편지의 눌림을 겹쳐 본다. 지워진 자국의 첫 방향이 윤서영의 이름 첫 획과 닮았음을 보지만, 글자 전체는 복원하지 않는다. 편지를 연도별로 다시 묶으며 가장 오래된 영역으로 들어갈 준비를 한다.

## Scenes

### Scene 1 — 눌린 선
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** 017화 다음 날 오전
**On stage:** 한서윤
**Staging:** none
- **Situation:** 세 편지와 투명지가 탁자에 놓인다.
- **Beat:** 압력 자국을 투명지에 옮겨 세 편지의 방향을 겹친다.
- **Turn:** 세 자국이 우연이 아니라 같은 손의 반복일 가능성이 생긴다.
- **Function:** 첫 글자 판독의 물리적 방법을 만든다.
- **Sensory-emotional:** 투명지가 종이 위에서 미끄러진다 → 서윤은 손끝을 적셔 위치를 고정한다.
- **Dialogue intent:** none
- **Transition out:** 첫 선의 시작점을 확인하려고 바닥에 편지를 옮긴다.
- **Paragraph outline:** 1. 도구와 편지를 꺼냄 2. 압력 자국을 옮김 3. 세 방향을 겹침 4. 우연 가능성을 검토함 5. 시작점을 표시함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 3×160 + transition 1×80 = 1,520
- **Est. length:** 1,500

### Scene 2 — 첫 획
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 현관 쪽 바닥 | **When:** 같은 날 오후
**On stage:** 한서윤
**Staging:** none
- **Situation:** 투명지와 세 편지가 바닥에 정렬된다.
- **Beat:** 첫 방향을 윤서영 이름의 첫 획과 비교하고, 같은 방향일 가능성을 확인한다.
- **Turn:** 지워진 이름이 어머니 이름과 연결될 가능성이 열리지만 글자 전체는 보류된다.
- **Function:** Series Hook의 첫 글자 단서를 실행한다.
- **Sensory-emotional:** 종이 밑의 바닥 냉기가 손목까지 올라온다 → 서윤은 투명지를 들어 올려 다시 겹친다.
- **Dialogue intent:** none
- **Transition out:** 이름 전체를 복원하지 않은 채 오래된 편지 더미를 찾는다.
- **Paragraph outline:** 1. 세 편지를 정렬함 2. 첫 방향을 읽음 3. 어머니 이름과 비교함 4. 유사성을 확인함 5. 전체 복원을 멈춤 6. 오래된 영역으로 이동함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×120 + POV 4×160 + transition 1×80 = 1,800
- **Est. length:** 1,800

### Scene 3 — 오래된 영역
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 벽 쪽 수납장 | **When:** 같은 날 밤
**On stage:** 한서윤
**Staging:** none
- **Situation:** 수납장 안쪽의 오래된 편지 더미가 열린다.
- **Beat:** 서윤은 첫 글자를 적지 않고 편지를 연도별로 다시 묶어 119·120통 영역을 앞으로 꺼낸다.
- **Turn:** 이름의 답보다 오래된 편지의 출발점을 먼저 확인하기로 한다.
- **Function:** P3 진입을 준비한다.
- **Sensory-emotional:** 오래된 종이에서 마른 먼지 냄새가 난다 → 서윤은 투명지를 더미 위에 올려 둔다.
- **Dialogue intent:** none
- **Transition out:** 오래된 편지 더미 위에 투명지가 놓인다.
- **Paragraph outline:** 1. 수납장을 엶 2. 오래된 더미를 꺼냄 3. 연도와 번호를 확인함 4. 첫 글자를 쓰려다 멈춤 5. 119·120통 영역을 앞으로 옮김
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

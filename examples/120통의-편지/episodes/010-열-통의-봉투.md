# Episode 010: 열 통의 봉투

## Summary
서윤은 역순으로 읽어 온 첫 열 통을 한꺼번에 펼쳐 놓고 봉투 수를 다시 센다. 열 통이어야 할 자리에 날짜 있는 봉투 열한 장이 놓여 있고, 그중 하나는 날짜가 없다. 서윤은 여분의 봉투를 편지로 확정하지 않은 채 별도로 보관하지만, 지금까지의 월별 구조에 처음으로 빈 날짜가 생긴다.

**Characters:** 한서윤, 윤서영 (편지 속 목소리)
**Locations:** 서윤의-아파트

## Purpose
첫 열 통의 월별 구조를 수량으로 검증하고, 날짜 없는 여분 봉투를 다음 회차들의 물성 단서로 고정한다.

## Reader Engagement (Episode Level)
### Personal Stake
열 통이라는 안전한 범위를 정한 순간 그 범위가 하나 더 많아지면, 서윤이 의지해 온 날짜와 수량의 질서가 흔들린다.
### Opening Question
열 통을 펼치면 정말 열 통만 나올까, 아니면 상자는 처음부터 월별 구조에 들어가지 않는 것을 하나 숨기고 있었을까?
### Reader Questions
- 여분 봉투는 편지인가, 빈 봉투인가?
- 왜 날짜가 없으며 왜 첫 열 통 사이에 들어와 있었는가?
- 이 수량 불일치가 2026년 7월의 이중 편지와 연결되는가?
### Stakes
서윤은 수량을 믿어야 다음 조사를 계속할 수 있지만, 수량을 믿는 순간 여분 봉투를 지워야 한다. 봉투를 남기면 질서가 무너지고, 제외하면 자신의 읽기 규칙이 증거를 선별하게 된다.

## Episode Arc
서윤은 필사한 한 장을 옆에 두고 첫 열 통을 펼친다. 날짜와 봉투 모서리를 확인하며 열 장을 세지만, 열한 번째 봉투가 섞여 있음을 발견한다. 처음에는 자신의 중복 계수를 의심하고, 다시 세어도 수량이 같자 무날짜 봉투를 월별 편지 더미에서 떼어 낸다. 다만 그것을 빈 봉투나 별도 편지라고 이름 붙이지 않고, 수첩에 ‘날짜 없음’만 기록한 채 다음 조사로 넘긴다.

## Scenes

### Scene 1 — 열 통을 펼치는 범위
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** Episode 009 다음 날 오전, 2026년 늦가을
**On stage:** 한서윤
**Staging:** none

- **Situation:** 서윤은 필사한 세 문장과 수첩을 옆에 두고, 첫 열 통만 펼쳐 비교하기로 한다.
- **Beat:** 역순 더미에서 첫 열 통을 꺼내 날짜가 보이는 면을 위로 놓고, 각 봉투의 모서리와 접힌 방향을 수첩에 표시한다. 열 통의 범위를 낮은 탁자 위에 맞추려 한다.
- **Turn:** 정해 둔 열 칸보다 봉투가 한 장 더 남는 것을 알아차린다.
- **Function:** 009화의 문장 비교를 전체 수량 검증으로 확장하고, 범위 안에 있는 이상을 시각화한다.
- **Sensory-emotional:** 늦가을 빛이 봉투의 날짜를 비스듬히 가린다 → 서윤은 숫자를 읽기 전에 봉투의 윤곽부터 세게 된다.
- **Dialogue intent:** none
- **Transition out:** 서윤은 자신이 한 장을 중복해서 꺼냈다고 생각하며, 열한 장을 다시 바닥에 내려놓는다.
- **Paragraph outline:**
  1. 필사한 세 문장과 수첩을 탁자 가장자리로 옮기는 동작
  2. 역순 더미에서 첫 열 통을 골라 날짜 면을 위로 놓음
  3. 봉투 모서리와 접힌 방향을 손끝으로 확인하는 세기
  4. 열 번째 자리를 정한 뒤에도 남은 봉투 하나를 발견함
  5. 자신의 중복 실수라고 판단하고 열한 장을 다시 모음
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 3×160 + transition 1×80 = 1,520
- **Est. length:** 1,500

### Scene 2 — 하나가 더 많은 자리
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 현관 쪽 바닥 | **When:** 같은 날 오전, Scene 1 직후
**On stage:** 한서윤
**Staging:** none

- **Situation:** 열한 장의 봉투가 바닥에 펼쳐지고, 서윤은 날짜와 수량을 두 방식으로 다시 확인한다.
- **Beat:** 날짜를 읽는 순서와 봉투의 물리적 위치를 세는 순서를 번갈아 적용한다. 열 장은 날짜가 이어지지만, 한 장은 날짜 칸을 비워 둔 채 섞여 있다. 서윤은 그 봉투를 빼고 세어도 열 장, 포함하면 열한 장이라는 결과를 기록한다.
- **Turn:** 오류가 자신의 세기 실수가 아니라 봉투 자체의 날짜 부재에서 생겼을 가능성을 인정한다.
- **Function:** Episode List의 ‘상자 수량이 하나 많다’를 단순한 오해가 아닌 반복 검증된 사건으로 만든다.
- **Sensory-emotional:** 차가운 바닥에 놓인 무날짜 봉투만 종이빛이 균일하다 → 서윤은 비어 있는 날짜 칸을 손가락으로 덮어 가리려 한다.
- **Dialogue intent:** none
- **Transition out:** 서윤은 무날짜 봉투를 월별 열 통의 가장자리에서 떼어 내고, 아직 이름을 붙이지 않은 별도 더미로 옮긴다.
- **Paragraph outline:**
  1. 현관 쪽 바닥에 열한 장을 날짜와 위치 두 기준으로 나누는 장면
  2. 날짜 있는 열 장의 순서를 확인하는 손과 시선
  3. 한 봉투의 날짜 칸이 비어 있음을 발견함
  4. 날짜순 세기와 물리적 세기를 번갈아 반복해 같은 수량을 얻음
  5. 무날짜 봉투를 빼도 열 장, 넣으면 열한 장이라는 기록
  6. 오류가 자신의 실수가 아닐 수 있음을 인정하고 봉투를 분리함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

### Scene 3 — 날짜 없는 봉투
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 벽 쪽 수납장 | **When:** 같은 날 해질 무렵
**On stage:** 한서윤
**Staging:** none

- **Situation:** 서윤은 무날짜 봉투를 열 통과 떨어뜨려 보관할지, 내용 없는 빈 봉투로 처리할지 결정해야 한다.
- **Beat:** 봉투의 앞뒤를 확인하지만 발신·수신 이름과 날짜가 모두 없다. 봉투 안쪽의 두께를 손끝으로 짐작하되 열지는 않는다. 수첩에는 ‘열 통 + 날짜 없음 1’이라고 적고, 무날짜 봉투를 수납장 안쪽 빈 칸에 세운다.
- **Turn:** 여분 봉투를 편지라고 부르지도, 빈 봉투라고 지우지도 않은 채 다음 회차의 관찰 대상으로 남긴다.
- **Function:** 수량 불일치의 정서적 비용을 보여 주고, 날짜 구조 바깥의 물건을 P2 폭로 없이 고정한다.
- **Sensory-emotional:** 수납장 안쪽의 어두운 빈 칸에서 봉투의 가장자리만 희게 선다 → 서윤은 손을 떼고도 봉투가 넘어지지 않는지 한 번 더 바라본다.
- **Dialogue intent:** none
- **Transition out:** 날짜 없는 봉투는 다른 편지와 닿지 않은 채 세워지고, 수첩에는 아직 열리지 않은 다음 조사 칸이 남는다.
- **Paragraph outline:**
  1. 해질 무렵 수납장 앞에서 무날짜 봉투의 앞뒤를 돌려 보는 손
  2. 빈 발신·수신 칸과 날짜 없는 표면을 확인함
  3. 봉투를 열지 않고 종이 두께만 손끝으로 판단하려는 망설임
  4. ‘열 통 + 날짜 없음 1’이라는 수량 기록
  5. 무날짜 봉투를 수납장 안쪽 빈 칸에 세워 다른 편지와 분리함
  6. 봉투가 넘어지지 않는지 확인한 뒤 방을 떠나는 닫힘
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

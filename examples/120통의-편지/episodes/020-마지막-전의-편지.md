## Purpose
120통을 열기 전 마지막 준비를 통해, 최종 편지의 장소를 서윤의 어린 시절로 되돌린다.

## Reader Engagement
### Personal Stake
마지막 편지가 집에 있다면 서윤의 어린 시절 기억도 편지의 일부가 된다.
### Opening Question
어머니는 왜 마지막 통을 상자 밖에 숨겼을까?
### Stakes
120통을 열면 답에 가까워지지만 장소를 확인하지 않으면 또 다른 기억을 놓칠 수 있다.

## Episode Arc
서윤은 119통의 순서와 120통 봉인 아래 연필 조각을 대조한다. 편지의 마지막 전 문장은 상자 밖의 어린 시절 장소를 가리킨다. 서윤은 120통을 다시 봉인하고 오래된 집으로 가는 준비를 한다.

## Scenes

### Scene 1 — 봉인 아래의 조각
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** 019화 다음 날 오전
**On stage:** 한서윤
**Staging:** none
- **Situation:** 119통과 120통의 봉인이 탁자에 놓인다.
- **Beat:** 연필 조각의 방향과 119통의 마지막 순서를 대조하고 봉인을 열지 않는다.
- **Turn:** 120통은 개봉보다 장소 확인이 먼저라는 판단이 생긴다.
- **Function:** 019화의 순서 후크를 실행한다.
- **Sensory-emotional:** 굳은 풀이 손톱에 걸린다 → 서윤은 힘을 빼고 봉투를 눕힌다.
- **Dialogue intent:** none
- **Transition out:** 마지막 전 편지의 뒷면을 확인한다.
- **Paragraph outline:** 1. 두 봉투를 꺼냄 2. 연필 조각 방향을 확인함 3. 순서 문장을 재독함 4. 봉인을 열려다 멈춤 5. 뒷면 확인으로 이동함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 3×160 + transition 1×80 = 1,520
- **Est. length:** 1,500

### Scene 2 — 상자 밖의 마지막 통
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 현관 쪽 바닥 | **When:** 같은 날 오후
**On stage:** 한서윤
**Staging:** none
- **Situation:** 119통의 마지막 전 문장과 120통 봉투가 바닥에 놓인다.
- **Beat:** 편지 뒷면의 장소 지시와 어린 시절 집의 구조를 기억 속 지도와 대조한다.
- **Turn:** 120통이 상자 안이 아니라 오래된 집의 특정 기억 장소와 연결된 가능성이 열린다.
- **Function:** Series Hook의 장소 방향을 실행한다.
- **Sensory-emotional:** 봉투의 모서리가 바닥의 먼지를 끌어온다 → 서윤은 기억 속 방의 위치를 수첩에 그린다.
- **Dialogue intent:** none
- **Transition out:** 현관 쪽에 갈 가방을 꺼낸다.
- **Paragraph outline:** 1. 뒷면의 짧은 지시를 읽음 2. 어린 시절 집의 구조를 떠올림 3. 지도와 기억을 대조함 4. 특정 장소 가능성을 확인함 5. 가방을 꺼내기로 함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×120 + POV 4×160 + transition 1×80 = 1,800
- **Est. length:** 1,800

### Scene 3 — 돌아갈 준비
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 벽 쪽 수납장 | **When:** 같은 날 밤
**On stage:** 한서윤
**Staging:** none
- **Situation:** 오래된 집으로 갈 가방과 120통 봉투가 수납장 앞에 놓인다.
- **Beat:** 서윤은 120통을 열지 않고 병원 자료·수첩·열쇠를 가방에 넣는다.
- **Turn:** 편지를 읽는 자리에서 기억의 장소로 직접 이동하기로 한다.
- **Function:** 021화의 이동을 준비한다.
- **Sensory-emotional:** 열쇠가 가방 안에서 다른 금속에 부딪힌다 → 서윤은 120통을 가장 위에 둔다.
- **Dialogue intent:** none
- **Transition out:** 오래된 집으로 향하는 가방 위에 120통 봉투가 놓인다.
- **Paragraph outline:** 1. 가방을 꺼냄 2. 필요한 물건을 분류함 3. 열쇠를 확인함 4. 120통을 열려다 보류함 5. 봉투를 가방 위에 놓음
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

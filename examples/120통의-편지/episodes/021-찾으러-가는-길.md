# Episode 021: 찾으러 가는 길

서윤은 120통과 열쇠를 들고 어머니의 옛집으로 간다. 오래 비어 있던 집의 나무 장롱과 안쪽 벽을 확인하며 120통이 상자 밖에 있다는 지시를 따라간다. 벽의 틈에서 봉투 모서리를 발견하지만 꺼내지 않고, 집이 기억보다 작고 낯설게 남아 있음을 기록한다.

## Purpose
편지의 장소 지시를 실제 공간에 대입하고, 마지막 통보다 먼저 벽 속 봉투의 존재를 확인한다.

## Reader Engagement
### Personal Stake
집이 기억보다 작다면 서윤의 어린 시절 기억도 편지처럼 다시 읽혀야 한다.
### Opening Question
벽 속에 있는 것은 마지막 통일까, 다른 시간일까?
### Stakes
봉투를 꺼내면 과거에 직접 손을 대게 되고, 멈추면 단서를 다시 놓칠 수 있다.

## Episode Arc
서윤은 옛집에 도착해 마당과 장롱을 확인한다. 집의 크기와 냄새가 기억과 어긋나는 가운데 안쪽 벽의 틈에서 봉투 모서리를 발견한다. 손을 대기 직전 멈추고 120통과 함께 다음 확인을 준비한다.

## Scenes

### Scene 1 — 작아진 집
**POV:** 한서윤 | **Location:** 어머니의-옛집 + 마당의 수도가 | **When:** 020화 다음 날 오전
**On stage:** 한서윤
**Staging:** none
- **Situation:** 서윤이 열쇠와 120통을 들고 옛집 마당에 도착한다.
- **Beat:** 수도가·현관 폭·창문 방향을 기억 속 지도와 대조한다.
- **Turn:** 집이 기억보다 작고 낮다는 사실을 인정한다.
- **Function:** 이동 후 장소 검증을 시작한다.
- **Sensory-emotional:** 수도가의 녹슨 금속 냄새 → 서윤은 열쇠를 쥔 손을 바꾼다.
- **Dialogue intent:** none
- **Transition out:** 현관을 지나 장롱과 안쪽 벽을 확인한다.
- **Paragraph outline:** 1. 마당 도착 2. 수도가와 현관을 확인 3. 기억 속 지도와 비교 4. 집의 크기 차이를 느낌 5. 열쇠로 문을 엶
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 3×160 + transition 1×80 = 1,520
- **Est. length:** 1,500

### Scene 2 — 장롱과 벽
**POV:** 한서윤 | **Location:** 어머니의-옛집 + 나무 장롱 앞 | **When:** 같은 날 오전
**On stage:** 한서윤
**Staging:** none
- **Situation:** 빈 집 안에서 장롱과 안쪽 벽이 마주 보인다.
- **Beat:** 녹나무 냄새·장롱의 위치·손이 닿지 않는 높이를 편지 지시와 대조한다.
- **Turn:** 벽의 틈이 기억 속 장소와 실제 구조에 동시에 맞는다는 가능성이 생긴다.
- **Function:** 봉투 모서리 발견을 준비한다.
- **Sensory-emotional:** 마른 나무가 손바닥의 열을 빼앗는다 → 서윤은 장롱을 밀지 않고 벽을 바라본다.
- **Dialogue intent:** none
- **Transition out:** 벽의 낮은 틈에 손전등을 비춘다.
- **Paragraph outline:** 1. 집 안의 냄새를 확인 2. 장롱 위치를 기억과 대조 3. 벽과 높이를 측정 4. 틈을 발견 5. 손전등을 준비함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×120 + POV 4×160 + transition 1×80 = 1,800
- **Est. length:** 1,800

### Scene 3 — 모서리
**POV:** 한서윤 | **Location:** 어머니의-옛집 + 안쪽 벽의 틈 | **When:** 같은 날 오후
**On stage:** 한서윤
**Staging:** none
- **Situation:** 손전등이 안쪽 벽의 틈과 그 안의 먼지를 비춘다.
- **Beat:** 벽 안쪽에서 봉투의 모서리를 발견하고 120통의 봉투와 종이 색을 비교한다.
- **Turn:** 봉투를 꺼내려다 손을 멈추고 발견만 기록한다.
- **Function:** Series Hook을 정확히 남기고 022화로 이월한다.
- **Sensory-emotional:** 먼지가 손등에 떨어진다 → 서윤은 봉투를 당기지 않고 120통을 옆에 둔다.
- **Dialogue intent:** none
- **Transition out:** 벽 속 봉투 모서리가 어둠 속에 남는다.
- **Paragraph outline:** 1. 손전등을 틈에 비춤 2. 먼지와 종이 모서리를 발견 3. 120통과 색을 비교 4. 손을 넣으려다 멈춤 5. 발견 위치를 기록함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

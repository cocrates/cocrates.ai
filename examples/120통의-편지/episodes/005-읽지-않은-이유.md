# Episode 005: 읽지 않은 이유

## Summary
서윤은 제5통을 읽기 전, 자신이 10년 동안 편지를 읽지 않은 이유를 수기로 적는다. 제5통의 문장은 그 변명을 정면으로 부정하지 않고, 서윤이 떠난 날의 기억에 작은 균열을 낸다. 봉투에는 유일하게 빗물 자국이 남아 있다.

## Purpose
읽지 않음의 방어를 현재 수기로 드러내고, 제5통의 빗물 자국으로 다음 회차의 물성 미스터리를 연다.

## Reader Engagement
### Personal Stake
서윤은 편지를 읽지 않은 책임을 어머니에게만 돌릴 수 없게 된다.
### Opening Question
내가 편지를 읽지 않은 것은 어머니를 미워해서였을까, 읽으면 무너질 것을 알고 있어서였을까?
### Reader Questions
빗물 자국은 언제 생겼고, 누가 편지를 젖게 했나?
### Stakes
자기변명이 깨지면 원망을 지탱하던 마지막 보호막도 약해진다.

## Episode Arc
서윤은 제5통을 열기 전 읽지 않은 이유를 여러 문장으로 적었다가, 그중 사실이 아닌 문장을 지운다. 제5통의 편지는 답장과 용서를 요구하지 않고 ‘읽지 않아도 살아갈 수 있다’는 서윤의 믿음을 비껴간다. 마지막에 봉투의 빗물 자국이 현재의 손바닥에 옮는다.

## Scenes
### Scene 1 — 변명의 목록
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** 2026년 늦가을, 제4통을 읽은 다음 날 밤
**On stage:** 한서윤
**Staging:** none
- **Situation:** 제5통과 수첩이 탁자 위에 놓여 있다.
- **Beat:** 서윤은 편지를 열기 전에 읽지 않은 이유를 적는다. 어머니가 먼저 연락하지 않았기 때문, 읽으면 용서해야 할 것 같기 때문, 이미 늦었기 때문이라는 문장을 차례로 쓰고 하나씩 지운다.
- **Turn:** 마지막에 ‘읽으면 내가 틀렸다는 것을 알게 될까 봐’라는 문장만 남긴다.
- **Function:** 개인적 방어의 핵심을 명시한다.
- **Sensory-emotional:** 지우개 가루와 연필심 가루 → 서윤은 지운 문장 위를 손바닥으로 덮는다.
- **Dialogue intent:** none
- **Transition out:** 서윤은 수첩을 접고 제5통을 현관 쪽 바닥으로 옮긴다.
- **Paragraph outline:** 1. 제5통과 수첩 배치 2. 첫 변명 쓰기 3. 연락·용서·지각 문장 삭제 4. 남은 핵심 문장 5. 지우개 가루를 덮는 손 6. 봉투를 현관으로 옮김
- **Unit budget:** dialogue 0 + action 4×180 + sensory 3×130 + POV 4×150 + transition 1×80 = 1,940
- **Est. length:** 1,900

### Scene 2 — 젖은 봉투
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 현관 쪽 바닥 | **When:** Scene 1 직후, 같은 밤
**On stage:** 한서윤
**Staging:** none
- **Situation:** 제5통이 차가운 현관 바닥에 놓인다.
- **Beat:** 서윤은 봉투의 빗물 자국을 발견하고 제5통 전문을 읽는다. 편지는 읽지 않는 사람을 탓하지 않지만, 기다림을 포기하지 않는 문장을 남긴다.
- **Turn:** 봉투를 들어 올린 뒤 물 자국이 손바닥에 둥글게 옮고, 서윤은 자국을 닦지 않는다.
- **Function:** 다음 회차의 물성 미스터리를 구체화하고 수기의 자기판단을 늦춘다.
- **Sensory-emotional:** 눅눅한 종이와 차가운 바닥 → 서윤은 손바닥의 자국을 바라본다.
- **Dialogue intent:** 윤서영의 편지는 답장을 요구하지 않으면서도 읽히기를 포기하지 않는 절제된 목소리.
- **Transition out:** 서윤은 빗물 자국이 남은 봉투를 제6통 위에 올려둔다.
- **Paragraph outline:** 1. 봉투의 물 자국 발견 2. 봉투 개봉 3. 제5통의 편지 전문 4. 읽지 않아도 된다는 문장과 기다림의 잔여 5. 자국이 손바닥으로 옮는 순간 6. 제6통 위에 봉투를 올림
- **Unit budget:** dialogue 4×260 + action 4×180 + sensory 4×130 + POV 4×150 + transition 1×80 = 3,240
- **Est. length:** 3,200

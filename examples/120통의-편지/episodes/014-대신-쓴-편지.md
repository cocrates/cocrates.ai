# Episode 014: 대신 쓴 편지

## Summary
서윤은 해안 병원으로 가기 전, 다른 필체로 쓰인 편지 한 통을 찾는다. 편지의 날짜는 어머니의 월별 기록 안에 있지만 글씨와 문장 습관이 다르다. 손을 다친 달에 누군가 대신 썼을 가능성이 열리고, 서윤은 대필자의 흔적을 확인하기 위해 병원 방문 가방에 그 편지를 추가한다.

**Characters:** 한서윤, 윤서영 (편지 속 목소리)
**Locations:** 서윤의-아파트

## Purpose
편지의 필체를 인물의 몸과 연결하고, 병원 방문 전에 대필자라는 새 질문을 만든다.

## Reader Engagement
### Personal Stake
필체가 어머니의 것이 아니라면, 서윤이 읽어 온 목소리의 일부도 흔들린다.
### Opening Question
어머니의 편지에서 어머니의 손이 사라진 달은 언제였을까?
### Stakes
대필을 인정하면 편지의 진정성을 의심해야 하고, 부정하면 다른 필체의 증거를 지워야 한다.

## Episode Arc
서윤은 병원 가방을 다시 열어 글씨가 다른 편지를 찾는다. 획의 방향과 문장 끝을 어머니의 다른 편지와 비교해 손 부상 가능성을 발견한다. 그 편지를 병원 기록 확인의 자료로 추가하지만, 대필자의 이름은 쓰지 않는다.

## Scenes

### Scene 1 — 다른 손의 획
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** 2026년 늦가을, 병원 방문 전날 오전
**On stage:** 한서윤
**Staging:** none
- **Situation:** 병원 가방을 확인하던 서윤이 익숙하지 않은 필체의 편지를 발견한다.
- **Beat:** 봉투의 날짜와 글자 높이·획의 방향·문장 끝을 다른 편지와 대조한다.
- **Turn:** 글씨가 어머니의 평소 필체와 다르다는 사실을 인정한다.
- **Function:** 대필 미스터리의 물리적 단서를 연다.
- **Sensory-emotional:** 잉크가 종이에서 멈춘 방향이 다르다 → 서윤은 목소리를 읽기 전에 손의 움직임을 센다.
- **Dialogue intent:** none
- **Transition out:** 해당 편지를 별도 종이에 놓고 날짜순 비교를 시작한다.
- **Paragraph outline:** 1. 가방을 열고 편지를 꺼냄 2. 획과 높이를 비교함 3. 문장 끝의 차이를 확인함 4. 평소 필체와 다름을 인정함 5. 별도 비교면을 꺼냄
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 3×160 + transition 1×80 = 1,520
- **Est. length:** 1,500

### Scene 2 — 손을 다친 달
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 현관 쪽 바닥 | **When:** 같은 날 오후
**On stage:** 한서윤
**Staging:** none
- **Situation:** 서로 다른 필체의 편지와 날짜 목록이 바닥에 펼쳐진다.
- **Beat:** 글씨가 바뀐 달의 앞뒤 편지를 확인하고, 획의 흔들림·잉크 농도·문장 길이를 비교한다.
- **Turn:** 손을 다친 달에 누군가 대신 썼을 가능성이 생긴다.
- **Function:** 필체를 단순 오류가 아니라 몸의 사건으로 바꾼다.
- **Sensory-emotional:** 종이 위의 잉크가 특정 방향에서만 번진다 → 서윤은 손의 통증을 상상하지 않고 날짜만 표시한다.
- **Dialogue intent:** none
- **Transition out:** 편지를 병원 방문 자료로 가져가기로 한다.
- **Paragraph outline:** 1. 바닥에 편지들을 날짜순으로 놓음 2. 필체 변화의 시작과 끝을 찾음 3. 흔들림과 잉크 농도를 비교함 4. 손 부상 가능성을 기록함 5. 병원 자료로 분류함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

### Scene 3 — 가방에 넣는 편지
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 벽 쪽 수납장 | **When:** 같은 날 밤
**On stage:** 한서윤
**Staging:** none
- **Situation:** 다른 필체의 편지가 병원 가방 위에 놓인다.
- **Beat:** 서윤은 대필자의 이름을 추정해 적으려다 지우고, 편지를 기존 자료와 함께 포장한다.
- **Turn:** 대필자가 아는 사람일 가능성을 배제하지 않은 채 병원으로 가져가기로 한다.
- **Function:** 다음 회차의 병원 방문과 대필자 질문을 연결한다.
- **Sensory-emotional:** 편지의 모서리가 가방 천을 눌러 작은 자국을 남긴다 → 서윤은 이름 대신 날짜만 접어 넣는다.
- **Dialogue intent:** none
- **Transition out:** 다른 필체의 편지가 가방 위에 올라가고 지퍼가 닫힌다.
- **Paragraph outline:** 1. 편지를 가방 위에 놓음 2. 대필자 이름을 쓰려다 지움 3. 날짜만 남김 4. 편지를 천으로 감쌈 5. 가방 위에 올리고 지퍼를 닫음
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

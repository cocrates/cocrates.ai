# Episode 011: 어머니의 계절

## Summary
서윤은 첫 열 통의 날짜를 달력에 옮겨 어머니가 편지를 쓴 계절의 순서를 복원한다. 날짜 없는 봉투를 제외하고도 달력에는 한 계절이 비어 있으며, 그 빈칸이 2017년 가을에 해당한다는 사실을 확인한다. 서윤은 무날짜 봉투를 빈 계절의 답으로 부르지 않은 채 달력 옆에 남겨 둔다.

## Purpose
편지의 날짜를 달력이라는 현재의 구조로 옮겨 2017년 가을의 공백을 물리적으로 확인하고, 기억의 빈칸과 기록의 빈칸을 분리한다.

## Reader Engagement (Episode Level)
### Personal Stake
달력에 빈칸을 그리는 순간 서윤은 자신이 잊었다고 믿는 계절을 눈앞의 물건으로 보게 된다.
### Opening Question
기억하지 못하는 계절은 편지가 없었던 계절인가, 아니면 편지를 읽지 못했던 계절인가?
### Reader Questions
- 2017년 가을에 편지가 없는 이유는 무엇인가?
- 무날짜 봉투가 그 공백을 메우는가?
- 서윤이 잊은 사건과 어머니가 쓰지 않은 기록은 같은가?
### Stakes
서윤은 달력을 믿으면 자신의 기억을 의심해야 하고, 기억을 믿으면 날짜의 빈칸을 지워야 한다.

## Episode Arc
서윤은 열 통의 날짜를 새 달력에 옮긴다. 날짜가 계절별로 이어지는 것을 확인하던 중 2017년 가을 칸만 비어 있음을 발견한다. 무날짜 봉투를 그 칸 옆에 놓아 보지만, 봉투를 공백의 답으로 정하는 순간 기록보다 앞서게 된다는 것을 깨닫고 분리한다. 달력의 빈칸과 수납장의 봉투가 서로를 가리키지만 아직 만나지 않는 상태로 회차를 닫는다.

## Scenes

### Scene 1 — 날짜를 옮기는 손
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 창가의 낮은 탁자 | **When:** 2026년 늦가을, Episode 010 다음 날 오전
**On stage:** 한서윤
**Staging:** none

- **Situation:** 서윤은 열 통의 날짜를 새 달력에 옮기고 무날짜 봉투는 수납장에 둔 채 시작한다.
- **Beat:** 날짜 있는 봉투 열 장을 한 장씩 펼쳐 달력의 월·일 칸에 표시하고, 날짜의 위치와 잉크 농도를 수첩에 짧게 기록한다.
- **Turn:** 날짜들이 매달 이어지는 배열을 이루고 있음을 확인한다.
- **Function:** 수량 단서를 시간 배열로 변환한다.
- **Sensory-emotional:** 달력 종이가 손바닥 아래에서 미끄러진다 → 서윤은 날짜를 읽기보다 칸의 간격을 먼저 맞춘다.
- **Dialogue intent:** none
- **Transition out:** 달력의 다음 칸을 넘기던 손이 한 계절의 빈 구간 앞에서 멈춘다.
- **Paragraph outline:**
  1. 수납장에 무날짜 봉투를 둔 채 달력과 열 봉투를 탁자에 놓음
  2. 날짜를 한 장씩 찾아 달력 칸에 표시함
  3. 잉크 농도와 날짜 위치를 수첩에 기록함
  4. 월별 표시가 이어지는 패턴을 발견함
  5. 다음 계절 칸에서 표시할 날짜를 찾지 못하고 멈춤
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 3×160 + transition 1×80 = 1,520
- **Est. length:** 1,500

### Scene 2 — 비어 있는 계절
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 현관 쪽 바닥 | **When:** 같은 날 오전, Scene 1 직후
**On stage:** 한서윤
**Staging:** none

- **Situation:** 달력의 계절별 표시 사이에 한 구간이 비어 있고, 서윤은 자신의 기억 수첩과 날짜를 대조한다.
- **Beat:** 달력의 앞뒤 날짜를 확인해 빈 구간이 2017년 가을임을 특정하고, 기억 수첩에서 그 계절의 기록을 찾는다. 수첩에는 짧은 날씨 기록만 있고 사건을 설명하는 문장은 없다.
- **Turn:** 기록이 없는 것과 기억하지 못하는 것이 같은 빈칸인지 구분할 수 없게 된다.
- **Function:** Episode List의 2017년 가을 공백을 달력과 기억의 충돌로 실행한다.
- **Sensory-emotional:** 바닥에 놓인 달력의 빈 칸이 주변 숫자보다 희게 보인다 → 서윤은 빈 칸을 채우지 않고 손가락으로 가장자리만 짚는다.
- **Dialogue intent:** none
- **Transition out:** 서윤은 무날짜 봉투를 수납장에서 꺼내 빈 가을 칸 옆에 놓아 보려 한다.
- **Paragraph outline:**
  1. 현관 쪽 바닥에 달력과 수첩을 나란히 펼침
  2. 앞뒤 날짜를 확인해 빈 구간의 연도와 계절을 좁힘
  3. 2017년 가을 칸을 기억 수첩에서 찾음
  4. 날씨 기록만 남은 페이지와 달력의 빈칸을 대조함
  5. 기록 부재와 기억 부재를 하나로 묶으려다 멈춤
  6. 무날짜 봉투를 빈 칸 옆에 놓을 준비를 함
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

### Scene 3 — 칸 옆의 봉투
**POV:** 한서윤 | **Location:** 서윤의-아파트 + 벽 쪽 수납장 | **When:** 같은 날 해질 무렵
**On stage:** 한서윤
**Staging:** none

- **Situation:** 무날짜 봉투가 2017년 가을의 빈 칸 옆에 놓이고, 서윤은 둘을 연결할지 분리할지 결정한다.
- **Beat:** 봉투를 달력 옆에 두고 크기·색·표면을 비교하지만 날짜가 없다는 사실 이상은 얻지 못한다. 봉투를 공백의 답으로 기록하려다 문장을 지우고, 달력은 접어 수첩 뒤에 둔다.
- **Turn:** 무날짜 봉투를 다시 수납장으로 돌려보내며 공백과 물건을 같은 증거로 취급하지 않기로 한다.
- **Function:** 공백을 확인하되 후반 폭로를 선취하지 않고 2017년 가을 미스터리를 유지한다.
- **Sensory-emotional:** 수납장 안쪽에서 봉투의 흰 가장자리와 달력의 빈 칸이 잠깐 겹친다 → 서윤은 달력을 먼저 접는다.
- **Dialogue intent:** none
- **Transition out:** 달력은 수첩 뒤에 접혀 들어가고 무날짜 봉투는 원래의 빈 칸으로 돌아간다. 2017년 가을은 빈 채로 남는다.
- **Paragraph outline:**
  1. 무날짜 봉투를 달력의 2017년 가을 칸 옆에 놓음
  2. 크기와 표면을 비교하지만 연결 근거를 찾지 못함
  3. 공백의 답이라고 적으려다 문장을 지움
  4. 달력을 접어 수첩 뒤에 보관함
  5. 봉투를 수납장 안쪽 빈 칸으로 되돌림
  6. 빈 계절과 빈 봉투가 서로 닿지 않은 채 남는 closing
- **Unit budget:** dialogue 0 + action 4×180 + sensory 2×120 + POV 4×160 + transition 1×80 = 1,680
- **Est. length:** 1,700

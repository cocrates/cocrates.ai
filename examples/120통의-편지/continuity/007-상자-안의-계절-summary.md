## Key Events (Episode Level)
- 계절별 봉투의 종이 결·냄새·잉크 농도가 서로 다름을 확인했다.
- 첫 겨울 편지에서 해안 병원이라는 장소명이 처음 등장했다.
- 병원명은 기록했으나 문맥과 의미는 보류했다.

## Character State Changes
- 한서윤: 날짜만이 아니라 계절의 물성으로 편지를 분류하기 시작함. 병원명을 조사 단서로 보유함.
- 윤서영: 겨울 편지의 반듯한 필체와 멈춤, 병원명으로 복원됨.

## Location State Changes
- 서윤의 아파트: 7월 봉투와 겨울 편지가 열린 상태로 분류됨.

## New Unresolved Threads

- 겨울 편지의 전체 문맥과 정확한 날짜.

## Resolved Threads

## Narrative Hooks for Next Episode

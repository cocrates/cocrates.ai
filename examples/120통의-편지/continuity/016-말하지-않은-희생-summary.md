- 거짓말의 수신인과 대가는 공개되지 않았다.
- 빈 수신인 칸이 다음 탐색의 물리적 단서가 되었다.

## Character State Changes
- 한서윤: 자신의 이름을 수신인 칸에 쓰지 않고, 대답할 권리를 유보함.
- 윤서영: 딸을 살리기 위해 거짓말했다고 적은 편지의 목소리로 확장됨.

## Location State Changes
- 서윤의 아파트: 2017년 9월 편지와 빗물·연필심 흔적이 빈 수신인 칸과 함께 보존됨.

## New Unresolved Threads

## Resolved Threads

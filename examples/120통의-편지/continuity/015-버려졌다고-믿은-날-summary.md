# Episode 015: 버려졌다고 믿은 날 — Summary

## Scenes Covered
| Sc | Title | Key Events |
|---|---|---|
| 1 | 보호자 칸 | 병원 기록의 보호자 칸에서 한서윤의 이름을 확인했지만 의미는 확정하지 않았다. |
| 2 | 떠난 날이 아닌 날 | 버려졌다고 믿었던 날의 편지가 그날을 다른 표현으로 부르는 것을 읽었다. |
| 3 | 밑단의 흔적 | 편지 밑단에서 말라붙은 빗물과 연필심 가루를 발견해 보존했다. |

## Key Events (Episode Level)
- 보호자 기록에 서윤의 이름이 존재한다는 사실만 확인됨.
- ‘버려졌다’는 기억과 편지의 다른 표현이 충돌함.
- 빗물과 연필심 가루가 다음 물리 단서로 보존됨.

## Character State Changes
- 한서윤: 기록의 이름과 기억을 하나의 결론으로 합치지 않고, 편지의 흔적을 보존하기로 함.
- 윤서영: 같은 날을 서윤과 다른 이름으로 기록한 편지의 목소리로 확장됨.

## Location State Changes
- 해안 병원: 보호자 기록 확인 장소가 됨.
- 서윤의 아파트: 기록지와 편지를 분리 보관하는 현재의 작업 공간이 됨.

## New Unresolved Threads
- 보호자 칸의 서윤 이름이 뜻하는 실제 역할.
- 편지 밑단의 빗물과 연필심 가루가 생긴 상황.
- ‘누군가 자리를 비운 날’이라는 표현의 의미.

## Resolved Threads
- 보호자 기록에 서윤의 이름이 있을 가능성.

## Narrative Hooks for Next Episode
서윤은 보호자 이름과 빗물·연필심 흔적을 따라, 어머니가 말하지 않은 희생의 범위를 추적한다. 병의 종류와 대필자 신원은 아직 보류한다.

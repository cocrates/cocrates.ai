# Episode 030: 이제야 읽었어요 — Summary

## Scenes Covered
| Sc | Title | Key Events |
|---|---|---|
| 1 | 상자 안의 한 통 | 서윤은 열린 우편 봉투를 비워 두고 완성된 답장을 120통 사이에 넣었다. |

## Key Events (Episode Level)
- 답장은 우편으로 발송되지 않고 120통 상자 안에 들어가 어머니의 기록과 같은 물성으로 보존되었다.
- 상자는 닫혔지만 서윤은 제1통의 첫 문장으로 돌아가 현재의 한 문장을 새로 놓았다.
- 「이제야 읽었어요」 아래의 흰 면과 연필 끝이 편지의 종료와 대화의 재개를 함께 남겼다.

## Character State Changes
- 한서윤: 120통과 답장을 상자 안에 보존하고, 첫 문장 아래에 현재의 응답을 남긴 상태. 어머니를 대신 해설하지 않고 자신의 읽기와 응답을 완결함.

## Location State Changes
- 어머니의 옛집: 120통과 답장이 닫힌 상자 안에 보존되고, 빈 우편 봉투와 첫 문장 아래의 새 문장이 남음. 벽 속 봉투는 봉인 상태.

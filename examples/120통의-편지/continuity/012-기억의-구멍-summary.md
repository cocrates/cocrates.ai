## Key Events (Episode Level)
- 서윤의 기억과 편지의 표현이 같은 날짜에서 충돌했다.
- 어머니는 그 날을 ‘떠난 날’이라 부르지 않고 문턱·다음 날을 가리키는 표현을 남겼다.
- 두 이름은 지워지지 않은 채 수첩에 병치되었고, 무날짜 봉투의 정체는 보류되었다.

## Character State Changes
- 한서윤: 자신의 기억을 거짓으로 지우지도, 편지를 최종 답으로 확정하지도 않았다.
- 윤서영: 특정 날짜를 다른 언어로 기록한 사실이 드러났다.

## Location State Changes
- 서윤의 아파트: 두 이름이 적힌 수첩은 달력 뒤에, 무날짜 봉투는 수납장 안쪽에 남았다.

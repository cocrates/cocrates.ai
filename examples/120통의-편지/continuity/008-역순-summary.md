## Key Events (Episode Level)
- 역순은 서윤이 선택한 자기보호이자 조사 규칙으로 고정되었다.
- 제8통의 마지막 문장이 최근 통부터 읽는 사람을 알고 쓴 것처럼 보였다.
- 어머니가 실제로 순서를 설계했다는 결론은 보류했다.

## Character State Changes
- 한서윤: 읽는 순서를 스스로 정하고, 의심을 확정하지 않은 채 기록함.
- 윤서영: 제8통의 문장 끝에 읽는 사람을 향한 듯한 빈틈을 남김.

## Location State Changes
- 서윤의 아파트: 제8통이 역순 더미에 놓이고 병원 편지는 겨울 더미에 보류됨.

## New Unresolved Threads

## Resolved Threads
- 역순 읽기 규칙을 서윤의 현재 선택으로 확정함.

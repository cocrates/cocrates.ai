## Key Events (Episode Level)
- 거짓말의 수신인이 서윤이 아닐 가능성이 열림.
- 모든 편지에서 이름이 지워진 듯한 동일 위치의 흔적이 발견됨.
- 이름은 복원하지 않고 물리적 흔적만 다음 회차로 이월됨.

## Character State Changes
- 한서윤: 지워진 이름을 복원할 수 있어도 복원하지 않기로 선택함.
- 윤서영: 수신인을 숨기는 반복된 기록 행위가 편지 속 목소리에 추가됨.

## Location State Changes
- 서윤의 아파트: 세 편지의 지워진 위치를 정렬한 보존 자료가 생김.

## New Unresolved Threads

## Resolved Threads

# Episode 024: 첫 질문 — Summary

## Scenes Covered
| Sc | Title | Key Events |
|---|---|---|
| 1 | 질문 다음의 빈자리 | 120통 첫 질문 아래 답을 놓을 듯한 빈 공간과 접힘을 확인했다. |
| 2 | 기다린다는 문장 | 질문이 혼자 끝나는 기록이 아니라 응답을 전제한 형식임을 확인했다. |
| 3 | 작은 글씨 | 질문 아래에서 어린 시절 서윤의 낙서를 발견하고, 어머니가 처음부터 답장을 기다렸음을 깨달았다. |

## Key Events (Episode Level)
- 질문 아래의 빈 면과 다른 잉크의 무게가 답장 공간의 가능성을 드러냈다.
- 120통의 문장은 질문 뒤에 응답할 사람의 자리를 남겨 두고 있었다.
- 질문 아래 어린 서윤의 연필 낙서가 발견되었다.
- 서윤은 낙서의 날짜와 의미를 해석하지 않고 투명한 면으로 보존했다.

## Character State Changes
- 한서윤: 120통이 처음부터 자신의 응답을 전제했음을 깨닫고, 어린 자신의 낙서를 보존하는 상태.

## Location State Changes
- 어머니의 옛집: 120통의 질문과 낙서가 벽 틈 가까이에서 확인되었다. 벽 속 봉투는 계속 봉인 보존된다.

## New Unresolved Threads
- 질문 아래 어린 서윤의 낙서가 쓰인 날과 의미.
- 120통의 질문 뒤에 이어지는 전체 문장과 출발점.
- 벽 속 봉투의 전문과 실제 수신인.

## Resolved Threads
- 120통이 답장할 사람을 전제한 편지였다는 서윤의 깨달음.
- 두 봉투 중 120통을 먼저 읽는 순서.

## Narrative Hooks for Next Episode
서윤은 질문 아래 남은 어린 시절의 낙서를 보존한 채 120통의 다음 내용을 앞에 둔다. 낙서가 남은 날과 120통의 출발점이 다음 회차로 이어진다.

## Key Events (Episode Level)
- 서윤은 120통을 읽은 뒤 남은 말들을 한 통의 답장으로 완성했다.
- 답장은 어머니를 대신 변호하거나 부치지 않은 이유를 판정하지 않고, 읽은 사실·변한 위치·남은 모름을 함께 보존한다.
- 발송과 상자 보관 중 어느 쪽도 선택하지 않은 채 두 목적지 앞에 섰다.

## Character State Changes
- 한서윤: 윤서영 이름이 있는 답장 본문을 완성하고 접었으며, 발송 여부를 결정해야 하는 상태.

## Location State Changes
- 어머니의 옛집: 완성된 접힌 답장, 열린 우편 봉투, 120통 상자가 같은 바닥에 놓임. 벽 속 봉투는 봉인 상태.

## New Unresolved Threads
- 완성된 답장을 우편으로 보낼지 120통 상자에 둘지의 최종 선택.

완성된 답장과 열린 우편 봉투, 120통 상자가 나란히 놓였고 서윤의 손은 어느 쪽에도 닿지 않았다. 다음 회차에서 서윤은 답장을 상자에 넣고 다시 첫 문장으로 돌아간다.

## Key Events (Episode Level)
- 서윤은 어머니의 120통 편지를 사흘간 열지 않다가 제1통을 개봉했다.
- 제1통은 2026년 11월 17일자로, 날씨·어린 시절의 파란 단추·답장을 요구하지 않겠다는 문장을 담고 있다.
- 서윤은 자신이 기억하는 2016년 9월의 이별과 편지 날짜 사이에 두 달의 공백이 있음을 발견했다.
- 편지 마지막 지시에 따라 상자 바닥에서 제2통의 모서리를 찾았다.

## Character State Changes
- 한서윤: 읽지 않음의 방어를 유지할 수 없게 되었고, 제2통을 열 준비 상태.
- 윤서영: 편지 속 목소리로 복원되기 시작했으나 의도와 사망 경위는 미해결.

## Location State Changes

- 어머니가 편지를 부치지 않은 이유.

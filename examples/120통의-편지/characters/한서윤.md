# 한서윤

## Basic Info
- Role: protagonist / first-person narrator
- Core Drive: 어머니 윤서영을 이해하고 자신이 버려졌다는 기억을 재검토한다.
- Central Conflict: 편지를 읽지 않은 선택을 인정하면 원망의 근거도 흔들린다.
- Arc Direction: 방어적 침묵에서 능동적 답장으로.

## Appearance & Behavior Traits
- Appearance: 서른두 살, 마른 체격, 손톱을 짧게 깎는다.
- Behavior: 중요한 물건을 날짜순으로 정리하다가도 감정이 앞서면 순서를 흐트러뜨린다.
- Voice: 짧고 관찰적인 수기 문장. 감정을 이름 붙이기보다 물건의 상태로 우회한다.
- Signature cues: 봉투 모서리, 잉크 냄새, 읽기 전의 망설임.

## Reference models (appearance + equipment states)
- base: 짙은 회색 니트, 검은 바지, 낡은 가죽 시계, 연필과 수첩.

## Key Relationships
- 윤서영 ↔ 한서윤: 모녀. 한서윤은 10년 전 어머니를 떠났다고 믿지만, 실제 기억은 비어 있다.
- 한민재 ↔ 한서윤: 외삼촌과 조카. 필요한 말만 주고받는 거리.

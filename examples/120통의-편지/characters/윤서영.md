# 윤서영

## Basic Info
- Role: mother / absent counterpart
- Core Drive: 딸에게 매달 한 번의 대화를 남긴다.
- Central Conflict: 직접 만나 설명할 수 없는 사정과 딸의 닫힌 마음.
- Arc Direction: 침묵 속 기록에서 딸의 응답으로.

## Appearance & Behavior Traits
- Appearance: 사진 속 오십대 초반, 짧은 파마머리와 얇은 금테 안경.
- Behavior: 문장을 쓰기 전에 날짜를 두 번 확인한다.
- Voice: 딸을 부르는 호칭을 쉽게 쓰지 않고, 날씨·사물에서 감정으로 들어간다.
- Signature cues: 지나치게 반듯한 글씨, 문장 끝의 짧은 망설임.

## Reference models (appearance + equipment states)
- base: 짙은 갈색 카디건, 은색 손목시계, 검은색 만년필.

## Key Relationships
- 한서윤 ↔ 윤서영: 딸에게 직접 답을 요구하지 않되, 언젠가 읽히기를 바라는 관계.
